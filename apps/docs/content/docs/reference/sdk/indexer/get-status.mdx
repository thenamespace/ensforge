Reads the indexer's health and how far each chain is indexed.

## When to use

Use to show a sync banner, or to wait until a write is indexed before reading it back.

## Details

- Chains are keyed by chain ID; `safe` and `finalized` are `null` when the indexer does not
  track them.

## Signature

```ts
function getStatus(
  client: Like,
  options?: getStatus.Options,
): Promise<getStatus.ReturnType>
```

Call it as `ens.indexer.getStatus(options)` on a client, or `Actions.indexer.getStatus(client, options)`.

`indexer.getStatus.request(options)` builds a deferred read for `Actions.batch`. See [Look up many at once](/docs/sdk/look-up-many-at-once).
