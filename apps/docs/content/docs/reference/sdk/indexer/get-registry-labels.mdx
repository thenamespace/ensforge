Lists the labels of an ENSv2 registry, optionally only those an address holds or does not hold.

## When to use

Use to browse a registry's names, e.g. the subnames recreated during migration.

## Details

- `owner` and `excludeOwner` cannot be combined.

## Signature

```ts
function getRegistryLabels(
  client: Like,
  options: getRegistryLabels.Options,
): Promise<getRegistryLabels.ReturnType>
```

Call it as `ens.indexer.getRegistryLabels(options)` on a client, or `Actions.indexer.getRegistryLabels(client, options)`.

`indexer.getRegistryLabels.request(options)` builds a deferred read for `Actions.batch`. See [Look up many at once](/docs/sdk/look-up-many-at-once).

## Parameters

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `limit` | `number` |  | Rows per page, 1–200. @default 50 |
| `cursor` | `string` |  | The previous page's `cursor`. |
| `includeTotal` | `boolean` |  | Count every row (`totalCount`); slower. |
| `address` (required) | `string` |  | Contract address. |
| `chainId` | `number` |  | Chain of the contract. @default the client's chain |
| `owner` | `string` |  | Only labels this address holds. |
| `excludeOwner` | `string` |  | Only labels this address does not hold. |

Also takes the [read options](/docs/reference/sdk/client#read-options).

## Returns

Resolves to `Page<RegistryLabel>`. One page of labels.
