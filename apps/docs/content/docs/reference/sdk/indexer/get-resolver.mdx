Reads a resolver and one page of the names bound to it.

## When to use

Use to see which names use a resolver before changing or replacing it.

## Details

- Bound names are paged: pass the answer's `cursor` for more.
- ENSv1 compatibility resolvers report the registry they mirror (`mirrors`).

## Signature

```ts
function getResolver(
  client: Like,
  options: getResolver.Options,
): Promise<getResolver.ReturnType>
```

Call it as `ens.indexer.getResolver(options)` on a client, or `Actions.indexer.getResolver(client, options)`.

`indexer.getResolver.request(options)` builds a deferred read for `Actions.batch`. See [Look up many at once](/docs/sdk/look-up-many-at-once).

## Parameters

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `at` | `{ readonly token: string } \| { readonly timestamp: bigint \| Date }` |  | Read at a snapshot: an earlier answer's `asOfToken`, or a time. |
| `finality` | `"latest" \| "safe" \| "finalized"` | `"latest"` | How settled the data must be: `latest`, `safe` or `finalized`. |
| `limit` | `number` |  | Rows per page, 1–200. @default 50 |
| `cursor` | `string` |  | The previous page's `cursor`. |
| `includeTotal` | `boolean` |  | Count every row (`totalCount`); slower. |
| `address` (required) | `string` |  | Contract address. |
| `chainId` | `number` |  | Chain of the contract. @default the client's chain |

Also takes the [read options](/docs/reference/sdk/client#read-options).

## Returns

Resolves to `Result<IndexedResolver> | null`. The resolver, or `null` when the indexer does not know it.
