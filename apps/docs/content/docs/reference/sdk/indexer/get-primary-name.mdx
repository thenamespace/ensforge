Reads an address's primary name from the indexer, verified on-chain when the indexer can.

## When to use

Use to label many accounts quickly; for an authoritative read, use `primaryName.get`.

## Details

- `name` is the verified answer when there is one, otherwise the indexed one; `source` says
  which.
- Every answer the indexer gave is in `answers`, with its status.

## Signature

```ts
function getPrimaryName(
  client: Like,
  options: getPrimaryName.Options,
): Promise<getPrimaryName.ReturnType>
```

Call it as `ens.indexer.getPrimaryName(options)` on a client, or `Actions.indexer.getPrimaryName(client, options)`.

`indexer.getPrimaryName.request(options)` builds a deferred read for `Actions.batch`. See [Look up many at once](/docs/sdk/look-up-many-at-once).

## Parameters

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `namespace` | `Namespace` |  | Only this naming system; every namespace the indexer serves when omitted. |
| `source` | `"indexed" \| "verified"` |  | Both, verified first, when omitted. |
| `address` (required) | `string` |  | The address, all lowercase or checksummed. |
| `coin` | `CoinType.Input` |  | Chain of the primary name, as a coin type. @default 60 (Ethereum) |

Also takes the [read options](/docs/reference/sdk/client#read-options).

## Returns

Resolves to `Result<IndexedPrimaryName>`. The primary name (`null` when none) and every answer.
