Reads an ENSv2 registry: the name it serves, its parent registry, when it was created and its counts.

## When to use

Use to inspect a registry found through a name's `subregistry`, e.g. in an explorer.

## Details

- `includeCounts` adds the number of labels, roles and events.

## Signature

```ts
function getRegistry(
  client: Like,
  options: getRegistry.Options,
): Promise<getRegistry.ReturnType>
```

Call it as `ens.indexer.getRegistry(options)` on a client, or `Actions.indexer.getRegistry(client, options)`.

`indexer.getRegistry.request(options)` builds a deferred read for `Actions.batch`. See [Look up many at once](/docs/sdk/look-up-many-at-once).

## Parameters

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `at` | `{ readonly token: string } \| { readonly timestamp: bigint \| Date }` |  | Read at a snapshot: an earlier answer's `asOfToken`, or a time. |
| `finality` | `"latest" \| "safe" \| "finalized"` | `"latest"` | How settled the data must be: `latest`, `safe` or `finalized`. |
| `address` (required) | `string` |  | Contract address. |
| `chainId` | `number` |  | Chain of the contract. @default the client's chain |
| `includeCounts` | `boolean` |  | Include label, role and event counts. |

Also takes the [read options](/docs/reference/sdk/client#read-options).

## Returns

Resolves to `Result<IndexedRegistry> | null`. The registry, or `null` when the indexer does not know it.
