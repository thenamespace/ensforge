Searches names by text.

## When to use

Use to back a name search box or autocomplete.

## Details

- Matches from the start of a label by default; `match: "contains"` matches anywhere.
- Searches every namespace the indexer serves unless `namespace` is set.

## Signature

```ts
function search(client: Like, options: search.Options): Promise<search.ReturnType>
```

Call it as `ens.indexer.search(options)` on a client, or `Actions.indexer.search(client, options)`.

`indexer.search.request(options)` builds a deferred read for `Actions.batch`. See [Look up many at once](/docs/sdk/look-up-many-at-once).

## Parameters

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `limit` | `number` |  | Rows per page, 1–200. @default 50 |
| `cursor` | `string` |  | The previous page's `cursor`. |
| `includeTotal` | `boolean` |  | Count every row (`totalCount`); slower. |
| `query` (required) | `string` |  |  |
| `namespace` | `Namespace` |  | Only this naming system; every namespace the indexer serves when omitted. |
| `match` | `"prefix" \| "contains"` | `"prefix"` | Whether `search` matches from the start of a label (`prefix`) or anywhere (`contains`). |

Also takes the [read options](/docs/reference/sdk/client#read-options).

## Returns

Resolves to `Page<IndexedName>`. One page of matching names.
