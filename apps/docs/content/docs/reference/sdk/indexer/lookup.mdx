Reads up to 1,000 names and addresses in one request.

## When to use

Use to render lists of names or accounts at once, e.g. a feed or a table of holders.

## Details

- Each input answers on its own: names with their state, addresses with their primary name and
  related names.
- An input that fails (an invalid name) reports `status` instead of failing the whole lookup.
- `profile: "detail"` adds records and resolution to each answer.

## Signature

```ts
function lookup(client: Like, options: lookup.Options): Promise<lookup.ReturnType>
```

Call it as `ens.indexer.lookup(options)` on a client, or `Actions.indexer.lookup(client, options)`.

`indexer.lookup.request(options)` builds a deferred read for `Actions.batch`. See [Look up many at once](/docs/sdk/look-up-many-at-once).

## Parameters

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `inputs` (required) | `readonly string[]` |  | Names and addresses, up to 1,000. |
| `namespace` | `Namespace` |  | Only this naming system; every namespace the indexer serves when omitted. |
| `profile` | `"feed" \| "detail"` |  | `detail` adds records and resolution. @default "feed" |

Also takes the [read options](/docs/reference/sdk/client#read-options).

## Returns

Resolves to `Result<{ readonly results: readonly LookupResult[] }>`. One answer per input, in input order.

| [`IndexerError`](/docs/reference/errors/indexer-error) | [`INDEXER_UNSUPPORTED`](/docs/reference/errors/INDEXER_UNSUPPORTED) | the indexer does not serve the query or its namespace. |
| [`IndexerError`](/docs/reference/errors/indexer-error) | [`INDEXER_UNAVAILABLE`](/docs/reference/errors/INDEXER_UNAVAILABLE), [`INDEXER_RATE_LIMITED`](/docs/reference/errors/INDEXER_RATE_LIMITED), [`INDEXER_BEHIND`](/docs/reference/errors/INDEXER_BEHIND), [`INDEXER_REQUEST_REJECTED`](/docs/reference/errors/INDEXER_REQUEST_REJECTED), [`INDEXER_RESPONSE_INVALID`](/docs/reference/errors/INDEXER_RESPONSE_INVALID) | the indexer is unavailable, rate limiting, behind, rejects the request or answers unexpectedly. |

It can also fail with the errors every read can (`Errors.CommonError`: `ConfigError`, `ContractRevertError`, `InternalError`, `NetworkError`).

See [How errors work](/docs/sdk/errors-explained).
