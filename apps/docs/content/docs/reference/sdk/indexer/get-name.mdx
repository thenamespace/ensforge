Reads one name from the indexer: owner, manager, expiry, resolver, records and protocol.

## When to use

Use to show a name page, or anywhere an indexed answer is fast enough; for an authoritative on-
chain read, use `name.get`.

## Details

- Basenames (`*.base.eth`) are read from the `basenames` namespace.
- Linea Names and Celonames have no indexer: their names fail with [`INDEXER_UNSUPPORTED`](/docs/reference/errors/INDEXER_UNSUPPORTED); read
  them on-chain with `name.get`.
- `authority` says which protocol holds the name (`ensV0`, `ensV1` or `ensV2`).
- `source: "verified"` asks the indexer to read the answer on-chain (bigname).
- Returns `null` when the indexer has no such name, or throws with `strict: true`.

## Signature

```ts
function getName(client: Like, options: getName.Options): Promise<getName.ReturnType>
```

Call it as `ens.indexer.getName(options)` on a client, or `Actions.indexer.getName(client, options)`.

`indexer.getName.request(options)` builds a deferred read for `Actions.batch`. See [Look up many at once](/docs/sdk/look-up-many-at-once).

## Returns

Resolves to `Result<IndexedNameDetail> | null`. The name, or `null` when the indexer does not know it.
