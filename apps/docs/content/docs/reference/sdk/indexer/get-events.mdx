Searches indexed ENS events by name, address, resolver, contract or block range.

## When to use

Use to audit events across names, e.g. every event a resolver emitted or a block range.

## Details

- Filters combine; without any, the newest events of every name are listed.
- Same event vocabulary as `event.get` and `indexer.getHistory`.

## Signature

```ts
function getEvents(client: Like, options: getEvents.Options): Promise<getEvents.ReturnType>
```

Call it as `ens.indexer.getEvents(options)` on a client, or `Actions.indexer.getEvents(client, options)`.

`indexer.getEvents.request(options)` builds a deferred read for `Actions.batch`. See [Look up many at once](/docs/sdk/look-up-many-at-once).
