Reads what the indexer serves for a namespace: its networks and which features are complete.

## When to use

Use to decide which features to show, e.g. hide verified records where they are unsupported.

## Signature

```ts
function getNamespace(
  client: Like,
  options?: getNamespace.Options,
): Promise<getNamespace.ReturnType>
```

Call it as `ens.indexer.getNamespace(options)` on a client, or `Actions.indexer.getNamespace(client, options)`.

`indexer.getNamespace.request(options)` builds a deferred read for `Actions.batch`. See [Look up many at once](/docs/sdk/look-up-many-at-once).

## Returns

Resolves to `Result<NamespaceInfo> | null`. The namespace's coverage, or `null` when the indexer does not know it.
