Recovers a label from its labelhash through the ENSv2 LabelStore.

## When to use

Use to display names that arrive as hashes, such as `[af2c…].eth` from events or indexers.

## Details

- ENSv2 registries store every label they register, so this covers every ENSv2 name.
- Returns `null` when the LabelStore has never seen the label.

## Signature

```ts
function getLabel(client: Like, options: getLabel.Options): Promise<getLabel.ReturnType>
```

Call it as `ens.name.getLabel(options)` on a client, or `Actions.name.getLabel(client, options)`.

`name.getLabel.request(options)` builds a deferred read for `Actions.batch`. See [Look up many at once](/docs/sdk/look-up-many-at-once).

## Parameters

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `labelhash` (required) | `Hex` |  | Keccak-256 hash of the label, as from `Name.labelhash`. |

Also takes the [read options](/docs/reference/sdk/client#read-options).

## Returns

Resolves to `string | null`. The label, or `null` when unknown.
