Resets the ENSv1 registry owner (manager) of an unwrapped `.eth` name, as its registrant. Resolves once the transaction is submitted.

## When to use

Use to take over the manager after receiving a `.eth` registrar token, or to repair a lost manager. Use [`reclaimSync`](/docs/reference/sdk/name/reclaim#wait-for-the-receipt-with-reclaimsync) to wait for the receipt.

## Details

- Only the registrar token holder (registrant) can reclaim.
- `owner` defaults to the signing account.

## Signature

Call it as `ens.name.reclaim(options)` on a client, or `Actions.name.reclaim(client, options)`.

## Wait for the receipt with `reclaimSync`
