Reads whether an ENSv1 name can migrate to ENSv2, how, and what it becomes.

## When to use

Use to drive a migration screen: route, blockers, resolver plan and the state after.

## Details

- `status`: `eligible`, `blocked` (see `blockers`), `migrated` or `not-required` (already
  on ENSv2, or not registered).
- `blockers` are checked for `account` (the client's account by default).
- `resolver.plan` shows what [`migration.migrate`](/docs/reference/sdk/migration/migrate) does with the current
  resolver for the same `resolver` option.
- With an indexer, `discovered` lists the records and subnames `migrate` carries over by
  default (read at the latest block).

## Signature

```ts
function get(client: Like, options: get.Options): Promise<get.ReturnType>
```

Call it as `ens.migration.get(options)` on a client, or `Actions.migration.get(client, options)`.

`migration.get.request(options)` builds a deferred read for `Actions.batch`. See [Look up many at once](/docs/sdk/look-up-many-at-once).

In React, use [`useMigrationStatus`](/docs/reference/react/use-migration-status).

## Parameters

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `name` (required) | `string` |  | ENS name. Normalized automatically. |
| `account` | `string` |  | Account that would migrate. Defaults to the client's account. |
| `resolver` | `"new" \| "owned" \| "keep" \| (string & {})` |  | The `resolver` option `migrate` would get. |

Also takes the [read options](/docs/reference/sdk/client#read-options).

## Returns

Resolves to `get.ReturnType`. Route, blockers, holder, resolver plan and the ENSv2 state after migrating.
