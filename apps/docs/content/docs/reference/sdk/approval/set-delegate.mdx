Approves or revokes a delegate who may edit a name's records on its public resolver. Resolves once the transaction is submitted.

## When to use

Use to let another account manage a profile on a PublicResolver. Use [`setDelegateSync`](/docs/reference/sdk/approval/set-delegate#wait-for-the-receipt-with-setdelegatesync) to wait for the receipt.

## Details

- A delegate can edit every record of the name; for per-record access on a
  PermissionedResolver use [`permission.setRecordAccess`](/docs/reference/sdk/permission/set-record-access).
- Basenames and Linea names approve it on their resolver on the L2. Other L2 namespaces have
  no delegates.
