Approves or revokes an operator for everything the signer holds on an ENS contract (`setApprovalForAll`). Resolves once the transaction is submitted.

## When to use

Use to let a marketplace or manager act on all your names in one contract. Use [`setOperatorSync`](/docs/reference/sdk/approval/set-operator#wait-for-the-receipt-with-setoperatorsync) to wait for the receipt.

## Details

- `contract`: the ENSv1 `"registry"`, `"registrar"` or `"wrapper"`, or any ENSv2 registry
  or resolver by address.
- `name` instead of `contract`: the contract that holds the name's token (for an unwrapped
  ENSv1 subname, the registry), on the chain the name lives on. For an L2 name the approval is
  sent on its L2.
- On ENSv2 registries an operator can transfer names; other changes need roles.

## Wait for the receipt with `setOperatorSync`
