Wraps an ENSv1 name in the NameWrapper. Resolves once the transaction is submitted.

## When to use

Use to turn an ENSv1 name into an ERC-1155 token, or to burn fuses on a `.eth` name. Use [`wrapSync`](/docs/reference/sdk/wrapper/wrap#wait-for-the-receipt-with-wrapsync) to wait for the receipt.

## Details

- `.eth` second-level names: one transaction from the registrant, which may burn owner
  fuses (`cannotUnwrap` first).
- Other names: the registry owner approves the NameWrapper, if needed, then wraps.
- The wrapped name stays with its current holder (registrant or manager) unless `owner` is
  given, also when an approved operator wraps it.
- Keeps the current resolver unless `resolver` is given.

<Callout type="warn" title="Gotchas">

- ENSv2 has no NameWrapper. Wrapped names migrate to ENSv2 like unwrapped ones.
- An operator of a non-`.eth` name's manager cannot approve the NameWrapper for the manager:
  the manager approves it first ([`NOT_APPROVED`](/docs/reference/errors/NOT_APPROVED)).

</Callout>

## Parameters

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `name` (required) | `string` |  | ENSv1 name. Normalized automatically. |
| `owner` | `string` |  | Owner of the wrapped name. Defaults to its current holder, else the signer. |
| `fuses` | `readonly Fuse.Name[]` |  | Fuses to burn while wrapping (`.eth` second-level names only). |
| `resolver` | `string` |  | Resolver to set. Defaults to the current one. |

Also takes the [write options](/docs/reference/sdk/client#write-options).

## Returns

Resolves to `Write.Result`. Submitted transaction hashes and the plan that produced them.

| Field | Type | Description |
| --- | --- | --- |
| `hash` | `Hex` | Hash of the last transaction. |
| `hashes` | `readonly Hex[]` | Every submitted transaction, in order. |
| `id` | `string` | EIP-5792 bundle id when the calls were sent as one batch. |
| `plan` | `Plan` | The plan the write executed: its steps, in order, as they were submitted. |

## Wait for the receipt with `wrapSync`

Wraps an ENSv1 name in the NameWrapper. Resolves once the receipt is in.

Use when the next step depends on the change being on-chain.

`wrapper.wrapSync` takes the same options plus [`confirmations` and `timeout`](/docs/reference/sdk/client#sync-options).

Resolves to `Write.SyncResult`. Receipts plus the submitted hashes and plan.
