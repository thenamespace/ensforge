Brings the NameWrapper's expiry of wrapped `.eth` names up to their registration's. Resolves once the transaction is submitted.

## When to use

Use when `migration.get` reports `wrapper-out-of-sync`: the name was renewed without the
NameWrapper being told, so after its old expiry the NameWrapper shows it with no owner or
fuses. Use [`syncSync`](/docs/reference/sdk/wrapper/sync#wait-for-the-receipt-with-syncsync) to wait for the receipt.

## Details

- Calls `ETHRenewerV1.syncWrapper`, which anyone may call; it changes nothing but the
  NameWrapper's expiry.
- Renewing through `registration.renew` syncs the NameWrapper as well.

## Returns

Resolves to `Write.Result`. Submitted transaction hashes and the plan that produced them.

| Field | Type | Description |
| --- | --- | --- |
| `hash` | `Hex` | Hash of the last transaction. |
| `hashes` | `readonly Hex[]` | Every submitted transaction, in order. |
| `id` | `string` | EIP-5792 bundle id when the calls were sent as one batch. |
| `plan` | `Plan` | The plan the write executed: its steps, in order, as they were submitted. |

## Wait for the receipt with `syncSync`

Brings the NameWrapper's expiry of wrapped `.eth` names up to their registration's. Resolves once the receipt is in.

Use when the next step depends on the change being on-chain, such as migrating the name.

`wrapper.syncSync` takes the same options plus [`confirmations` and `timeout`](/docs/reference/sdk/client#sync-options).

Resolves to `Write.SyncResult`. Receipts plus the submitted hashes and plan.
