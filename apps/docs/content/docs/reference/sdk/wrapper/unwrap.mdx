Unwraps an ENSv1 name from the NameWrapper. Resolves once the transaction is submitted.

## When to use

Use to return a wrapped name to the ENSv1 registry (and the `.eth` registrar). Use [`unwrapSync`](/docs/reference/sdk/wrapper/unwrap#wait-for-the-receipt-with-unwrapsync) to wait for the receipt.

## Details

- `owner` becomes the registry owner and, for `.eth` names, the registrant. Defaults to the
  signer.
- Blocked once `cannotUnwrap` is burned.

## Signature

```ts
function unwrap(
  client: Like,
  options: unwrap.Options & Write.Options,
): Promise<unwrap.ReturnType>
```

Call it as `ens.wrapper.unwrap(options)` on a client, or `Actions.wrapper.unwrap(client, options)`.

## Parameters

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `name` (required) | `string` |  | ENSv1 name. Normalized automatically. |
| `owner` | `string` |  | Owner after unwrapping. Defaults to the signer. |

Also takes the [write options](/docs/reference/sdk/client#write-options).

## Returns

Resolves to `Write.Result`. Submitted transaction hashes and the plan that produced them.

| Field | Type | Description |
| --- | --- | --- |
| `hash` | `Hex` | Hash of the last transaction. |
| `hashes` | `readonly Hex[]` | Every submitted transaction, in order. |
| `id` | `string` | EIP-5792 bundle id when the calls were sent as one batch. |
| `plan` | `Plan` | The plan the write executed: its steps, in order, as they were submitted. |

## Wait for the receipt with `unwrapSync`

Unwraps an ENSv1 name from the NameWrapper. Resolves once the receipt is in.

Use when the next step depends on the change being on-chain.

`wrapper.unwrapSync` takes the same options plus [`confirmations` and `timeout`](/docs/reference/sdk/client#sync-options).

Resolves to `Write.SyncResult`. Receipts plus the submitted hashes and plan.
