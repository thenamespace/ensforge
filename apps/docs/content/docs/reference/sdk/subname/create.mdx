Creates a subname, routed by its parent: an ENSv2 subregistry, the ENSv1 registry or the NameWrapper. Resolves once the transaction is submitted.

## When to use

Use to give out names under one you own, such as `pay.alice.eth`. Use [`createSync`](/docs/reference/sdk/subname/create#wait-for-the-receipt-with-createsync) to wait for the receipt.

## Details

- ENSv2 parents: the child is registered in the parent's subregistry. A parent without one
  gets a UserRegistry deployed and attached in the same plan (`plan.deploys`).
- ENSv2 children never expire by default and their owner gets the roles the `.eth`
  registrar grants (resolver, subregistry, transfers); `roles` and `expiry` override them.
- ENSv1 parents use `setSubnodeRecord`; wrapped parents take `fuses` and an `expiry`.
- By default the child gets its own PermissionedResolver with `records` written at creation;
  `resolver: "parent"` shares the parent's resolver, `null` creates it without one.
- `upsert` updates an existing child's resolver and records instead of failing.

<Callout type="warn" title="Gotchas">

- A subregistry deployed here is not emancipated unless `emancipate` is set: its owners can
  remove and repoint children.
- Under a wrapped parent, `parentCannotControl` and `canExtendExpiry` need `cannotUnwrap`
  burned on the parent ([`INVALID_RECORD_VALUE`](/docs/reference/errors/INVALID_RECORD_VALUE)), and an emancipated child cannot be updated
  until it expires ([`FUSE_BURNED`](/docs/reference/errors/FUSE_BURNED)).

</Callout>

## Parameters

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `name` (required) | `string` |  | Full name of the child, e.g. `pay.alice.eth`. Normalized automatically. |
| `owner` | `string` | the signing account | Owner of the child. |
| `resolver` | `string \| "parent" \| null` |  | Resolver of the child. By default it gets its own PermissionedResolver; `"parent"` uses the parent's resolver and `null` none. |
| `records` | `Omit<recordSet.Options, "name" \| "resolver" \| "clear" \| "pubkey">` |  | Records of the child. |
| `expiry` | `bigint` | never for ENSv2 children; for wrapped children, the maximum when `parentCannotControl` is burned, else none | Expiry as a Unix timestamp. |
| `fuses` | `readonly Fuse.Name[]` |  | NameWrapper fuses to burn on the child (wrapped ENSv1 parents). |
| `roles` | `readonly Role.Name[] \| bigint` |  | ENSv2 roles for the child's owner, by name or bitmap. |
| `emancipate` | `boolean` |  | Emancipate the parent's subregistry if this plan deploys it. |
| `upsert` | `boolean` |  | Update the child's resolver and records if it already exists. |

Also takes the [write options](/docs/reference/sdk/client#write-options).
