Links an ENS name to the records of another name on the same PermissionedResolver. Resolves once the transaction is submitted.

## When to use

Use to make several names share one set of records, such as aliases of a main name. Use [`linkSync`](/docs/reference/sdk/resolver/link#wait-for-the-receipt-with-linksync) to wait for the receipt.

## Details

- `to` is a name whose records the name will read and write, or a record ID from
  [`resolver.getLink`](/docs/reference/sdk/resolver/get-link).
- Both names must use the same PermissionedResolver, and the target must already have records.
- Needs the `link` role on the resolver.

## Signature

```ts
function link(
  client: Like,
  options: link.Options & Write.Options,
): Promise<link.ReturnType>
```

Call it as `ens.resolver.link(options)` on a client, or `Actions.resolver.link(client, options)`.

## Parameters

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `name` (required) | `string` |  | ENS name. Normalized automatically. |
| `to` (required) | `string \| { recordId: bigint } \| null` |  | Name or record ID to link to, or `null` to unlink: the name then gets an empty record of its own, while the records it shared stay with the other names. |

Also takes the [write options](/docs/reference/sdk/client#write-options).

## Returns

Resolves to `Write.Result`. Submitted transaction hashes and the plan that produced them.

| Field | Type | Description |
| --- | --- | --- |
| `hash` | `Hex` | Hash of the last transaction. |
| `hashes` | `readonly Hex[]` | Every submitted transaction, in order. |
| `id` | `string` | EIP-5792 bundle id when the calls were sent as one batch. |
| `plan` | `Plan` | The plan the write executed: its steps, in order, as they were submitted. |

## Wait for the receipt with `linkSync`

Links an ENS name to the records of another name on the same PermissionedResolver. Resolves once the receipt is in.

Use when the next step depends on the change being on-chain.

`resolver.linkSync` takes the same options plus [`confirmations` and `timeout`](/docs/reference/sdk/client#sync-options).

Resolves to `Write.SyncResult`. Receipts plus the submitted hashes and plan.
