Calls the resolver of an ENS name with raw calldata through the Universal Resolver (ENSIP-10).

## When to use

Use to read resolver profiles ensforge has no action for. Use [`record.get`](/docs/reference/sdk/record/get) for
the standard records.

## Details

- Finds the resolver like any ENS client: the name's own, a parent's wildcard, or off-chain
  through CCIP-Read.
- `data` is the resolver call, with the name's node as its first argument.
- Returns the ABI-encoded result and the resolver the Universal Resolver called: for ENSv1
  names ENSv2 serves through the ENSv1 bridge, the bridge itself (`record.get` and
  `resolver.get` report the ENSv1 resolver behind it).

## Signature

```ts
function resolve(client: Like, options: resolve.Options): Promise<resolve.ReturnType>
```

Call it as `ens.resolver.resolve(options)` on a client, or `Actions.resolver.resolve(client, options)`.

`resolver.resolve.request(options)` builds a deferred read for `Actions.batch`. See [Look up many at once](/docs/sdk/look-up-many-at-once).

## Returns

Resolves to `{ readonly data: Hex; readonly resolver: Address }`. The ABI-encoded result and the resolver that answered.
