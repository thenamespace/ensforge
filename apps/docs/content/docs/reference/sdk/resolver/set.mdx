Points an ENS name at a resolver. Resolves once the transaction is submitted.

## When to use

Use to move a name to another resolver, or to remove it with `resolver: null`. Use [`setSync`](/docs/reference/sdk/resolver/set#wait-for-the-receipt-with-setsync) to wait for the receipt.

## Details

- ENSv1 names change it in the ENS registry, or through the NameWrapper when wrapped.
- ENSv2 names change it in the registry holding them (`setResolver` on the token).
- `"default"` is the ENSv1 public resolver, for ENSv1 names.
- Basenames and Linea Names change it on their L2, in the registry or Linea's NameWrapper,
  where `"default"` is the family's current resolver. A Linea name accepts only Linea's
  PublicResolver: its Ethereum resolver reads no other.

<Callout type="warn" title="Gotchas">

- Records stay on the old resolver; copy them with `record.set` first.
- ENSv2 names have no shared default resolver: create one with [`resolver.create`](/docs/reference/sdk/resolver/create).

</Callout>

## Parameters

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `name` (required) | `string` |  | ENS name. Normalized automatically. |
| `resolver` (required) | `Address \| "default" \| null` |  | New resolver, `"default"` for the ENSv1 public resolver, or `null` to remove it. |

Also takes the [write options](/docs/reference/sdk/client#write-options).

## Returns

Resolves to `Write.Result`. Submitted transaction hashes and the plan that produced them.

| Field | Type | Description |
| --- | --- | --- |
| `hash` | `Hex` | Hash of the last transaction. |
| `hashes` | `readonly Hex[]` | Every submitted transaction, in order. |
| `id` | `string` | EIP-5792 bundle id when the calls were sent as one batch. |
| `plan` | `Plan` | The plan the write executed: its steps, in order, as they were submitted. |

## Plan methods

Each method takes the same options as `resolver.set` and sends nothing. See [Preview before sending](/docs/sdk/preview-before-sending).

| Method | Description |
| --- | --- |
| `resolver.set.prepare(options)` | Builds the plan without sending anything. |
| `resolver.set.simulate(options)` | Simulates the plan with `eth_call`, reporting each step. |
| `resolver.set.estimateGas(options)` | Estimates the gas and ETH the plan needs. |

## Wait for the receipt with `setSync`

Points an ENS name at a resolver. Resolves once the receipt is in.

Use when the next step depends on the change being on-chain.

`resolver.setSync` takes the same options plus [`confirmations` and `timeout`](/docs/reference/sdk/client#sync-options).

Resolves to `Write.SyncResult`. Receipts plus the submitted hashes and plan.
