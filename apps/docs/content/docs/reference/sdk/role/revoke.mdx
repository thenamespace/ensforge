Revokes ENSv2 roles from an account on a name, or at the root of a registry or resolver. Resolves once the transaction is submitted.

## When to use

Use to take back powers granted with [`role.grant`](/docs/reference/sdk/role/grant). Use [`revokeSync`](/docs/reference/sdk/role/revoke#wait-for-the-receipt-with-revokesync) to wait for the receipt.

## Details

- Revoking needs the matching admin roles.
- Some roles regenerate the name's token ID; the plan carries a `TOKEN_ID_REGENERATED` warning.

## Signature

Call it as `ens.role.revoke(options)` on a client, or `Actions.role.revoke(client, options)`.

## Parameters

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `holder` (required) | `string` |  | Account that loses the roles. |
| `roles` (required) | `readonly Role.Name[] \| bigint` |  | Roles by name, e.g. `["setResolver"]`, or as a bitmap. |
| `target` (required) | `"registry" \| "resolver"` |  | Registry or PermissionedResolver roles (resolvers: root only). |
| `name` | `string` |  | ENS name whose registry or resolver to use. Normalized automatically. |
| `contract` | `string` |  | Registry or resolver address, instead of the name's. |
| `root` | `boolean` |  | Root roles, applying to every name, instead of the name's. |

Also takes the [write options](/docs/reference/sdk/client#write-options).

## Returns

Resolves to `Write.Result`. Submitted transaction hashes and the plan that produced them.

| Field | Type | Description |

| `id` | `string` | EIP-5792 bundle id when the calls were sent as one batch. |
| `plan` | `Plan` | The plan the write executed: its steps, in order, as they were submitted. |

## Wait for the receipt with `revokeSync`

Revokes ENSv2 roles from an account on a name, or at the root of a registry or resolver. Resolves once the receipt is in.

Use when the next step depends on the change being on-chain.

`role.revokeSync` takes the same options plus [`confirmations` and `timeout`](/docs/reference/sdk/client#sync-options).

Resolves to `Write.SyncResult`. Receipts plus the submitted hashes and plan.
