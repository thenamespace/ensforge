Sets the metadata URI of an ENSv2 registry. Resolves once the transaction is submitted.

## When to use

Use to point a registry's token metadata at your own service. Use [`setUriSync`](/docs/reference/sdk/registry/set-uri#wait-for-the-receipt-with-seturisync) to wait for the receipt.

## Details

- Keeps the current URI renderer unless `renderer` is given; `null` removes it.
- Needs the `setUri` root role.

## Signature

```ts
function setUri(
  client: Like,
  options: setUri.Options & Write.Options,
): Promise<setUri.ReturnType>
```

Call it as `ens.registry.setUri(options)` on a client, or `Actions.registry.setUri(client, options)`.

## Returns

Resolves to `Write.Result`. Submitted transaction hashes and the plan that produced them.

| Field | Type | Description |

| `hash` | `Hex` | Hash of the last transaction. |
| `hashes` | `readonly Hex[]` | Every submitted transaction, in order. |
| `id` | `string` | EIP-5792 bundle id when the calls were sent as one batch. |
| `plan` | `Plan` | The plan the write executed: its steps, in order, as they were submitted. |

## Wait for the receipt with `setUriSync`

Sets the metadata URI of an ENSv2 registry. Resolves once the receipt is in.

Use when the next step depends on the change being on-chain.

`registry.setUriSync` takes the same options plus [`confirmations` and `timeout`](/docs/reference/sdk/client#sync-options).

Resolves to `Write.SyncResult`. Receipts plus the submitted hashes and plan.
