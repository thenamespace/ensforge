Lists the saved plans of this client's chain and of its `chains`, newest first.

## When to use

Use to offer unfinished registrations or migrations after a reload.

## Details

- Filter by the account that prepared them and by status (`pending`, `completed`,
  `failed`).

## Signature

```ts
function list(client: Like, options: list.Options): Promise<list.ReturnType>
```

Call it as `ens.plan.list(options)` on a client, or `Actions.plan.list(client, options)`.

`plan.list.request(options)` builds a deferred read for `Actions.batch`. See [Look up many at once](/docs/sdk/look-up-many-at-once).

| Option | Type | Default | Description |

| `account` | `string` |  | Only plans prepared for this account. |
| `status` | `Plan.Record["status"]` |  | Only plans with this status. |

| Field | Type | Description |
