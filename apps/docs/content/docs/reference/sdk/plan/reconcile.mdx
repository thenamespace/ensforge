Records a transaction sent outside ensforge as a plan step's submission.

## When to use

Use when a step was sent from another device or the wallet lost track, so resuming does not send it again.

## Details

- The transaction must exist and come from the plan's account, or call one of the step's
  contracts.
- [`plan.resume`](/docs/reference/sdk/plan/resume) then waits for it instead of sending the step.

## Signature

```ts
function reconcile(client: Like, options: reconcile.Options): Promise<reconcile.ReturnType>
```

Call it as `ens.plan.reconcile(options)` on a client, or `Actions.plan.reconcile(client, options)`.

`plan.reconcile.request(options)` builds a deferred read for `Actions.batch`. See [Look up many at once](/docs/sdk/look-up-many-at-once).
