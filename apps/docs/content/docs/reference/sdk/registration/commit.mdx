Commits to registering `.eth` names, the first half of a registration. Resolves once the transaction is submitted.

## When to use

Use when registration is split across sessions or devices; `register` alone does both halves. Use [`commitSync`](/docs/reference/sdk/registration/commit#wait-for-the-receipt-with-commitsync) to wait for the receipt.

## Details

- Takes the same options as [`registration.register`](/docs/reference/sdk/registration/register); they are hashed into the commitment.
- Keep the returned `secret`, then call `register` with the same options and `secret` once the
  commitment is ready (see [`registration.getCommitmentStatus`](/docs/reference/sdk/registration/get-commitment-status)).

<Callout type="warn" title="Gotchas">

- `.prepare` and `.simulate` without `secret` use a throwaway secret.

</Callout>

## Parameters

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `names` (required) | `string \| readonly string[]` |  | One or more `.eth` second-level names; several share one plan. Normalized automatically. |
| `duration` (required) | `bigint` |  | Registration length in seconds, e.g. `Duration.years(1)`. |
| `owner` | `string` | the signing account | Owner of the names. |
| `resolver` | `string \| null` |  | Resolver for the names. By default each name gets its own PermissionedResolver, deployed in the same plan with `records` written at creation. `"owned"` uses the signer's shared PermissionedResolver (the ENS app's address), deployed once and reused; its roles cover every name on it. `null` registers without a resolver. |
| `records` | `Omit<recordSet.Options, "name" \| "resolver" \| "clear" \| "pubkey">` |  | Records for every name, written when its resolver is created (or right after registering). |
| `primaryName` | `boolean` |  | Set the (single) name as the signer's primary name; adds its `eth` address record. |
| `paymentToken` | `PaymentToken` | `"usdc"` | Token to pay with. |
| `subregistry` | `string` |  | ENSv2 registry for the names' subnames. |
| `referrer` | `Hex` |  | Referrer recorded by the registrar: 32 bytes, or an address (left-padded). |
| `secret` | `Hex` |  | Secret from an earlier `commit` or `register`, to finish that registration. |

Also takes the [write options](/docs/reference/sdk/client#write-options).

## Returns

Resolves to `Write.Result & { readonly secret: Hex; readonly commitments: readonly Hex[] }`. Submitted hashes, the plan, the secret and the commitments.

## Plan methods

Each method takes the same options as `registration.commit` and sends nothing. See [Preview before sending](/docs/sdk/preview-before-sending).

| Method | Description |
| --- | --- |
| `registration.commit.prepare(options)` | Builds the plan without sending anything. |
| `registration.commit.simulate(options)` | Simulates the plan with `eth_call`, reporting each step. |
| `registration.commit.estimateGas(options)` | Estimates the gas and ETH the plan needs. |

## Wait for the receipt with `commitSync`

Commits to registering `.eth` names, the first half of a registration. Resolves once the receipt is in.

Use when the next step depends on the change being on-chain.

`registration.commitSync` takes the same options plus [`confirmations` and `timeout`](/docs/reference/sdk/client#sync-options).

Resolves to `commitSync.ReturnType`. Receipts, the secret, the commitments and when they can be used.
