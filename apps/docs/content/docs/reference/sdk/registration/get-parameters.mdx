Reads the `.eth` registration settings: contracts, commitment window, minimum duration, grace
period and accepted payment tokens.

## When to use

Use to build registration UIs: the commitment wait, the shortest duration, and which tokens
to offer.

## Signature

```ts
function getParameters(
  client: Like,
  options?: getParameters.Options,
): Promise<getParameters.ReturnType>
```

Call it as `ens.registration.getParameters(options)` on a client, or `Actions.registration.getParameters(client, options)`.

`registration.getParameters.request(options)` builds a deferred read for `Actions.batch`. See [Look up many at once](/docs/sdk/look-up-many-at-once).
