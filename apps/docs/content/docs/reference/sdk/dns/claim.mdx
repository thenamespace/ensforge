Imports a DNS name into ENS with a DNSSEC proof of its `_ens` TXT record. Resolves once the transaction is submitted.

## When to use

Use to claim a DNS name after adding the TXT record `_ens.<name>` = `a=<address>`. Use [`claimSync`](/docs/reference/sdk/dns/claim#wait-for-the-receipt-with-claimsync) to wait for the receipt.

## Details

- The name goes to the address in the TXT record, whoever sends the claim.
- The proof comes from the deployment's DNSSEC gateway unless `proof` is given.
- With `resolver`, the claim also sets it; then only the DNS owner may send it. Set records
  with [`record.set`](/docs/reference/sdk/record/set) afterwards.

<Callout type="warn" title="Gotchas">

- Read [`dns.getStatus`](/docs/reference/sdk/dns/get-status) first: a proof that does not verify on-chain fails.

</Callout>

## Parameters

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `name` (required) | `string` |  | DNS name. Normalized automatically. |
| `proof` | `Proof` |  | Proof from [`dns.getProof`](/docs/reference/sdk/dns/get-proof), instead of fetching one. |
| `resolver` | `string` |  | Resolver to set while claiming. |
| `gatewayUrls` | `readonly string[]` |  | DNSSEC gateways to fetch the proof from, instead of the deployment's. |

Also takes the [write options](/docs/reference/sdk/client#write-options).

## Returns

Resolves to `Write.Result`. Submitted transaction hashes and the plan that produced them.

| Field | Type | Description |

| `hashes` | `readonly Hex[]` | Every submitted transaction, in order. |
| `id` | `string` | EIP-5792 bundle id when the calls were sent as one batch. |
| `plan` | `Plan` | The plan the write executed: its steps, in order, as they were submitted. |

## Wait for the receipt with `claimSync`

Imports a DNS name into ENS with a DNSSEC proof of its `_ens` TXT record. Resolves once the receipt is in.

Use when the next step depends on the change being on-chain.

`dns.claimSync` takes the same options plus [`confirmations` and `timeout`](/docs/reference/sdk/client#sync-options).

Resolves to `Write.SyncResult`. Receipts plus the submitted hashes and plan.
