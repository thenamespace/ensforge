## Indexers

### `bigname`

The bigname indexer (`api.bigname.sh`), the indexer the ENS app uses.

```ts
function bigname(options: RestIndexerOptions & { /** Revalidate repeated reads with ETags. @default false */ cache?: boolean | undefined; } = {}): Indexer
```

Use for ENS names on mainnet and Sepolia: ENSv1 and ENSv2 state, records, subnames, history,
permissions, and verified (on-chain) records and primary names.

- Public hosts: `https://api.bigname.sh` (mainnet) and `https://sepolia.api.bigname.sh`
  (Sepolia); other chains need `url`.
- Answers can be pinned to a snapshot (`at`) and read at `safe` or `finalized` finality.
- What it serves is read from its `/status` and `/namespaces` routes on first use: a client on
  another chain, or a namespace it does not index yet (Basenames, at the time of writing),
  fails with [`INDEXER_UNSUPPORTED`](/docs/reference/errors/INDEXER_UNSUPPORTED), so `fallback` moves on.
- `cache: true` revalidates repeated reads with ETags.

```ts title="Mainnet or Sepolia"
import { Ensforge } from "@ensforge/sdk"
import { bigname, indexerActions } from "@ensforge/sdk/indexer"

const ens = Ensforge.create({ publicClient, indexer: bigname() }).extend(indexerActions())
```

```ts title="A self-hosted bigname"
import { bigname } from "@ensforge/sdk/indexer"

const indexer = bigname({ url: "https://bigname.internal", headers: { authorization } })
```

```ts title="With Goldsky for Basenames"
import { bigname, fallback, goldsky } from "@ensforge/sdk/indexer"

const indexer = fallback([bigname(), goldsky()])
```

### `defineIndexer`

Builds an indexer from your own functions, e.g. for an in-house API or a test double.

```ts
function defineIndexer(adapter: Adapter): Indexer
```

Use when your data source does not speak bigname's REST API; for one that does (a self-hosted
bigname, a proxy), pass its URL to `bigname({ url })` instead.

- Implement only the queries you serve; the others fail with [`INDEXER_UNSUPPORTED`](/docs/reference/errors/INDEXER_UNSUPPORTED), so
  `fallback` moves on to the next indexer.
- Queries arrive validated: names normalized, addresses checksummed, the namespace resolved.
- Return `null` from single-resource queries (`getName`, `getRecords`, …) when nothing exists.
- Throw an ensforge error (e.g. `Errors.IndexerError`) to control how a failure is reported;
  anything else becomes [`INDEXER_UNAVAILABLE`](/docs/reference/errors/INDEXER_UNAVAILABLE).

```ts title="An adapter for an in-house API"
import { defineIndexer } from "@ensforge/sdk/indexer"

const inHouse = defineIndexer({
  id: "in-house",
  getSubnames: async ({ name, cursor }, { signal }) => {
    const page = await api.subnames(name, cursor, { signal })
    return { items: page.items, cursor: page.next, hasMore: page.next !== null, totalCount: null }
  },
})
```

```ts title="Trying it before bigname"
import { Ensforge } from "@ensforge/sdk"
import { bigname, fallback } from "@ensforge/sdk/indexer"

const ens = Ensforge.create({ publicClient, indexer: fallback([inHouse, bigname()]) })
```

```ts title="A test double"
import { defineIndexer } from "@ensforge/sdk/indexer"

const indexer = defineIndexer({
  id: "test",
```

### `fallback`

Asks several indexers in order: each query goes to the first one that can answer it.

```ts
function fallback(indexers: readonly Indexer[], options: { readonly on?: readonly FallbackReason[] | undefined } = {}): Indexer
```

Use to combine indexers with different coverage (bigname for Sepolia and verified reads,
Goldsky for Basenames) or to keep reading when one is down.

- The next indexer is asked when one is unavailable, rate limiting, behind, or does not serve
  the query or its namespace (`on` narrows this). Not found is an answer: it is not retried.
- Every answer reports the indexer that gave it (`indexer`).
- Cursors and `asOfToken`s are tagged with the indexer that issued them; follow-up pages and
  snapshot reads go back to that indexer only.
- When every indexer fails, the last failure that was not [`INDEXER_UNSUPPORTED`](/docs/reference/errors/INDEXER_UNSUPPORTED) is reported.

```ts title="bigname first, Goldsky after"
import { Ensforge } from "@ensforge/sdk"
import { bigname, fallback, goldsky } from "@ensforge/sdk/indexer"

const ens = Ensforge.create({ publicClient, indexer: fallback([bigname(), goldsky()]) })
```

```ts title="Only when the first is down"
import { bigname, fallback, goldsky } from "@ensforge/sdk/indexer"

const indexer = fallback([bigname(), goldsky()], { on: ["unavailable", "rateLimited"] })
```

```ts title="A self-hosted indexer first"
import { bigname, fallback } from "@ensforge/sdk/indexer"

const indexer = fallback([bigname({ url: "https://bigname.internal" }), bigname()])
```

### `goldsky`

Goldsky's ENS indexer (`ens-api.goldsky.com`), which serves bigname's API for ENS and
Basenames.

```ts
function goldsky(options: RestIndexerOptions = {}): Indexer
```

Use for Basenames (`*.base.eth`), or as a second indexer behind bigname on mainnet.

- Mainnet only (ENS on chain 1, Basenames on Base); other chains need `url`.
- Reads the latest state only: `at` and `finality: "safe" | "finalized"` fail with
  [`INDEXER_UNSUPPORTED`](/docs/reference/errors/INDEXER_UNSUPPORTED), as does `getResolvers`.
- Answers carry fewer fields than bigname's (no verified records, subnames without expiry);
  missing fields are `null`.

```ts title="Basenames"
import { Ensforge } from "@ensforge/sdk"
import { goldsky, indexerActions } from "@ensforge/sdk/indexer"

const ens = Ensforge.create({ publicClient, indexer: goldsky() }).extend(indexerActions())
const name = await ens.indexer.getName({ name: "jesse.base.eth" })
```

```ts title="Behind bigname"
import { bigname, fallback, goldsky } from "@ensforge/sdk/indexer"

const indexer = fallback([bigname(), goldsky()])
```

```ts title="With an API key header"
import { goldsky } from "@ensforge/sdk/indexer"

const indexer = goldsky({ headers: { "x-api-key": key } })
```

### `paginate`

Iterates over every page of an indexer list, following `cursor` until the last page.

```ts
async function* paginate<options extends { cursor?: string | undefined }, item>( load: (options: options) => Promise<Page<item>>, options: options, ): AsyncGenerator<Page<item>, void, undefined>
```

Use to walk a whole list, such as a name's subnames or an address's names; `break` stops
requesting further pages.

```ts title="Every subname of a name"
import { paginate } from "@ensforge/sdk/indexer"

for await (const page of paginate(ens.indexer.getSubnames, { name: "ens.eth", limit: 200 })) {
  render(page.items)
}
```

```ts title="Collecting names, at most 1,000"
import { paginate } from "@ensforge/sdk/indexer"

const names: string[] = []
for await (const page of paginate(ens.indexer.getNamesForAddress, { address })) {
  names.push(...page.items.map((item) => item.name))
  if (names.length >= 1000) break
}
```

```ts title="With a standalone action"
import { Actions } from "@ensforge/sdk"
import { paginate } from "@ensforge/sdk/indexer"

const pages = paginate(
  (options: Actions.indexer.getSubnames.Options) => Actions.indexer.getSubnames(ens, options),
  { name: "ens.eth" },
)
```
