## What happened

The bundler rejected the HCA UserOperation.

## What to show users

| Title | Message | Action |
| --- | --- | --- |
| Transaction not sent | The service that sends your transaction turned it down. | Try again. |

## How to fix

Check the bundler URL and EntryPoint v0.7 support; HCA UserOperations must be signed by the owner.

## Retry safety

Retrying the same call can succeed (`retryable: true`).
