## What happened

The HCA session policy does not allow this call.

## What to show users

| Title | Message | Action |
| --- | --- | --- |
| Not allowed | Your session does not allow this action. | Approve it from your wallet instead. |

## How to fix

Sessions may register names, deploy the session resolver and set its records; send other calls as the owner.

## Retry safety

Retrying the same call fails the same way until the cause is fixed (`retryable: false`).
