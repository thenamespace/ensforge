## What happened

The HCA session is expired, revoked or for another resolver.

## What to show users

| Title | Message | Action |
| --- | --- | --- |
| Session ended | Your session has expired or was revoked. | Start a new session. |

## How to fix

Authorize a new session with hca.authorizeSession.
