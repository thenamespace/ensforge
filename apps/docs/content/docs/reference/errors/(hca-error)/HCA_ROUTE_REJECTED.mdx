## What happened

The execution service returned a different transaction than ensforge asked for; nothing was signed.

## What to show users

| Title | Message | Action |
| --- | --- | --- |
| Transaction stopped | The transaction prepared for your ENS account was not the one you asked for. | Nothing was signed. Try again later. |

## How to fix

`details` lists each difference. Do not retry blindly: check the executor's configuration.

## Retry safety

Retrying the same call fails the same way until the cause is fixed (`retryable: false`).
