## What happened

The Rhinestone SDK does not support the standalone ENS HCA.

## What to show users

| Title | Message | Action |
| --- | --- | --- |
| Configuration problem | This app is misconfigured for ENS accounts. |  |

## How to fix

Use a Rhinestone SDK with standalone HCA support (`ens-standalone-1.1.0`).

## Retry safety

Retrying the same call fails the same way until the cause is fixed (`retryable: false`).
