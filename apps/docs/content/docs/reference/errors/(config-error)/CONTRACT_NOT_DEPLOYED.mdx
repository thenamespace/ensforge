## What happened

No contract is deployed at the called address.

## What to show users

| Title | Message | Action |
| --- | --- | --- |
| Network mismatch | The ENS contracts were not found on this network. | Check that your wallet is on the right network. |

## How to fix

Check that the client's chain matches the deployment profile.

## Retry safety

Retrying the same call fails the same way until the cause is fixed (`retryable: false`).

## Actions that throw it

Any action can fail with `ConfigError`: it is part of `Errors.CommonError`.
