The ensforge client or a call is configured incorrectly. Fix the code; retrying does not help.

Any action can fail with `ConfigError`: it is part of `Errors.CommonError`.

## Codes

| Code | Meaning | Retryable |
| --- | --- | --- |
| [`UNKNOWN_CHAIN`](/docs/reference/errors/UNKNOWN_CHAIN) | ensforge has no ENS deployment for this chain. | No |
| [`INVALID_DEPLOYMENT`](/docs/reference/errors/INVALID_DEPLOYMENT) | The deployment profile is invalid. | No |
| [`CONTRACT_NOT_DEPLOYED`](/docs/reference/errors/CONTRACT_NOT_DEPLOYED) | No contract is deployed at the called address. | No |
| [`WALLET_NOT_CONFIGURED`](/docs/reference/errors/WALLET_NOT_CONFIGURED) | This action needs a wallet client with an account. | No |
| [`INDEXER_NOT_CONFIGURED`](/docs/reference/errors/INDEXER_NOT_CONFIGURED) | This action needs an indexer. | No |
| [`CCIP_READ_DISABLED`](/docs/reference/errors/CCIP_READ_DISABLED) | This name resolves off-chain, and CCIP-Read is disabled. | No |
| [`INVALID_ACTION_GROUP`](/docs/reference/errors/INVALID_ACTION_GROUP) | A decorator added an action group with a reserved name. | No |
| [`CHAIN_NOT_CONFIGURED`](/docs/reference/errors/CHAIN_NOT_CONFIGURED) | The client has no clients for chain ?. | No |
