## What happened

ensforge has no ENS deployment for this chain.

## What to show users

| Title | Message | Action |
| --- | --- | --- |
| Network not supported | ENS is not available on this network. | Switch to Ethereum mainnet or Sepolia. |

## How to fix

Pass `deployment` to Ensforge.create, e.g. Deployments.define(\{ name, chainId, v2 \}).

## Retry safety
