## What happened

A decorator added an action group with a reserved name.

## What to show users

| Title | Message | Action |
| --- | --- | --- |
| Configuration problem | This app is misconfigured. |  |

## How to fix

Rename the group; chain, account, deployment, publicClient, config and extend are reserved.

## Retry safety

Retrying the same call fails the same way until the cause is fixed (`retryable: false`).

## Actions that throw it

No action names this code in its documented errors.

Any action can fail with `ConfigError`: it is part of `Errors.CommonError`.

## Catch it

`Errors.hasCode("INVALID_ACTION_GROUP")` narrows to this error. See [Handle errors](/docs/sdk/handle-errors).
