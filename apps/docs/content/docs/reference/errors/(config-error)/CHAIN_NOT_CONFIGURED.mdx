## What happened

The client cannot reach chain ?.

## What to show users

| Title | Message | Action |
| --- | --- | --- |
| Network not set up | This app is not set up for that network. |  |

## How to fix

Add a transport for chain \<chainId\> to Ensforge.create, e.g. `transports: { <chainId>: http(rpcUrl) }`.

## Retry safety

Retrying the same call fails the same way until the cause is fixed (`retryable: false`).
