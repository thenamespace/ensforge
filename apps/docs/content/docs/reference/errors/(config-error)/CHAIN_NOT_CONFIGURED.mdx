## What happened

The client has no clients for chain ?.

## What to show users

| Title | Message | Action |
| --- | --- | --- |
| Network not set up | This app is not set up for that network. |  |

## How to fix

Add chain \<chainId\> to `chains` in Ensforge.create, e.g. `chains: { <chainId>: { publicClient, walletClient } }`.

## Retry safety

Retrying the same call fails the same way until the cause is fixed (`retryable: false`).

## Actions that throw it

| Action | When |
| --- | --- |
| [`primaryName.set`](/docs/reference/sdk/primary-name/set) | for an L2 that is not in the client's `chains`. |

Any action can fail with `ConfigError`: it is part of `Errors.CommonError`.
