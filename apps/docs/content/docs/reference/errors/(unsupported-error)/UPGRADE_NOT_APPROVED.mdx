## What happened

The upgrade target is not an approved implementation.

## What to show users

| Title | Message | Action |
| --- | --- | --- |
| Upgrade not allowed | This upgrade has not been approved by ENS. |  |

## Retry safety

Retrying the same call fails the same way until the cause is fixed (`retryable: false`).

## Actions that throw it

| Action | When |
| --- | --- |
| [`registry.upgrade`](/docs/reference/sdk/registry/upgrade) | when the target is not approved. |
| [`resolver.upgrade`](/docs/reference/sdk/resolver/upgrade) | when the resolver or target cannot be upgraded. |

Any write can fail with `UnsupportedError`: it is part of `Errors.WriteError`.

## Catch it

`Errors.hasCode("UPGRADE_NOT_APPROVED")` narrows to this error. See [Handle errors](/docs/sdk/handle-errors).
