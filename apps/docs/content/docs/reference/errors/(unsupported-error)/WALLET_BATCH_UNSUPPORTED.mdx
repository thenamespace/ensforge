## What happened

The wallet cannot send calls as one batch.

## What to show users

| Title | Message | Action |
| --- | --- | --- |
| Wallet not supported | Your wallet cannot send these transactions together. |  |

## How to fix

Use `mode: "auto"` or `mode: "sequential"`.

## Retry safety

Retrying the same call fails the same way until the cause is fixed (`retryable: false`).
