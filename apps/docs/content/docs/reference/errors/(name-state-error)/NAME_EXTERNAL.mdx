## What happened

The name is not in ENS's registries: its parent's resolver serves it.

## What to show users

| Title | Message | Action |
| --- | --- | --- |
| Managed elsewhere | This name is managed by the service that issued it, not by ENS directly. | Manage it in the app or network that issued it. |

## How to fix

Its parent's namespace manages it (an L2, or the provider's app or API); ENS writes cannot change it.

## Retry safety

Retrying the same call fails the same way until the cause is fixed (`retryable: false`).
