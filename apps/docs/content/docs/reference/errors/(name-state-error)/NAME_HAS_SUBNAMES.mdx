## What happened

The name has subnames, which would keep resolving without it.

## What to show users

| Title | Message | Action |
| --- | --- | --- |
| Name has subnames | This name has subnames, which would keep resolving without it. | Remove its subnames first. |

## How to fix

Remove its subnames first, or pass `allowOrphanedSubnames: true`.

## Retry safety

Retrying the same call fails the same way until the cause is fixed (`retryable: false`).
