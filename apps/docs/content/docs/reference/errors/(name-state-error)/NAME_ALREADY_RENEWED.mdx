## What happened

Every name already expires at or after `until`.

## What to show users

| Title | Message | Action |
| --- | --- | --- |
| Already renewed | These names are already renewed until the date you chose. |  |

## How to fix

Nothing is left to renew; a retry with the same `until` renews only names still short of it.

## Retry safety

Retrying the same call fails the same way until the cause is fixed (`retryable: false`).

## Actions that throw it

| Action | When |
| --- | --- |
| [`registration.renew`](/docs/reference/sdk/registration/renew) | when a name is neither registered nor in its grace period, or every name already reaches `until`. |

## Catch it

`Errors.hasCode("NAME_ALREADY_RENEWED")` narrows to this error. See [Handle errors](/docs/sdk/handle-errors).
