## What happened

The signature does not authorize this change.

## What to show users

| Title | Message | Action |
| --- | --- | --- |
| Signature not valid | The signature does not authorize this change. | Sign the request again with the right account. |

## How to fix

Sign again with the account being named (or the contract's Ownable owner), for the same name, chains and expiry.

## Retry safety

Retrying the same call fails the same way until the cause is fixed (`retryable: false`).
