## What happened

The name has no resolver.

## What to show users

| Title | Message | Action |
| --- | --- | --- |
| No resolver | This name is not set up to hold records yet. | Set a resolver first. |

## How to fix

Set one with resolver.set.

## Retry safety

Retrying the same call fails the same way until the cause is fixed (`retryable: false`).
