## What happened

No contract is deployed at the resolver address.

## What to show users

| Title | Message | Action |
| --- | --- | --- |
| Resolver not deployed | The resolver address has no contract, so it cannot hold records. | Choose a deployed resolver. |

## How to fix

Deploy it first, for example with resolver.create, or pass another resolver.

## Retry safety

Retrying the same call fails the same way until the cause is fixed (`retryable: false`).

## Actions that throw it

| Action | When |
| --- | --- |
| [`record.set`](/docs/reference/sdk/record/set) | when no contract is deployed at the resolver it writes to. |
| [`registration.commit`](/docs/reference/sdk/registration/commit) | when no contract is deployed at the given resolver or subregistry. |
| [`registration.register`](/docs/reference/sdk/registration/register) | when no contract is deployed at the given resolver or subregistry. |
| [`resolver.set`](/docs/reference/sdk/resolver/set) | when no contract is deployed at the resolver address, unless `allowNonContract`. |

## Catch it

`Errors.hasCode("RESOLVER_NOT_DEPLOYED")` narrows to this error. See [Handle errors](/docs/sdk/handle-errors).
