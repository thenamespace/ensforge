## What happened

undefined is not a valid ENS name.

## What to show users

| Title | Message | Action |
| --- | --- | --- |
| Invalid name | This is not a valid ENS name. | Check the spelling and remove unsupported characters. |

## How to fix

Names must normalize under ENSIP-15, e.g. `nick.eth`.

## Retry safety

Retrying the same call fails the same way until the cause is fixed (`retryable: false`).
