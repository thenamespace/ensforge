## What happened

Part of this plan was sent through a route (`via`), which resuming needs again.

## What to show users

| Title | Message | Action |
| --- | --- | --- |
| Cannot continue | This transaction must be continued the same way it was started. |  |

## How to fix

Pass the same `via` to plan.resume, e.g. `via: hca()`.

## Retry safety

Retrying the same call fails the same way until the cause is fixed (`retryable: false`).
