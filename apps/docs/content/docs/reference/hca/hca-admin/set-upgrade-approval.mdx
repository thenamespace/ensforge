Approves or revokes an implementation in the HCA upgrade set (role holders only). Resolves once the transaction is submitted.

## When to use

Use when the DAO allows existing HCAs to upgrade to an implementation, or withdraws that.

## Signature

```ts
function setUpgradeApproval(
  client: Like,
  options: setUpgradeApproval.Options & Write.Options,
): Promise<setUpgradeApproval.ReturnType>
```

Call it as `ens.hcaAdmin.setUpgradeApproval(options)` on a client, or `Actions.hcaAdmin.setUpgradeApproval(client, options)`.

## Parameters

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `implementation` (required) | `string` |  | HCA implementation. |
| `approved` (required) | `boolean` |  | `true` to approve, `false` to revoke. |

Also takes the [write options](/docs/reference/sdk/client#write-options).

## Returns

Resolves to `Write.Result`. Submitted transaction hashes and the plan that produced them.

| Field | Type | Description |
| --- | --- | --- |
| `hash` | `Hex` | Hash of the last transaction. |
| `hashes` | `readonly Hex[]` | Every submitted transaction, in order. |
| `id` | `string` | EIP-5792 bundle id when the calls were sent as one batch. |
| `plan` | `Plan` | The plan the write executed: its steps, in order, as they were submitted. |
