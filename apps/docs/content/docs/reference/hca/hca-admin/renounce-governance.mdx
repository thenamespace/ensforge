Renounces ownership of the HCA factory, freezing its implementation approvals (factory owner only). Resolves once the transaction is submitted.

## When to use

Use to make the set of deployable HCA implementations permanent.

## Signature

```ts
function renounceGovernance(
  client: Like,
  options: renounceGovernance.Options & Write.Options,
): Promise<renounceGovernance.ReturnType>
```

Call it as `ens.hcaAdmin.renounceGovernance(options)` on a client, or `Actions.hcaAdmin.renounceGovernance(client, options)`.

## Parameters

Also takes the [write options](/docs/reference/sdk/client#write-options).

## Returns

Resolves to `Write.Result`. Submitted transaction hashes and the plan that produced them.

| Field | Type | Description |
| --- | --- | --- |
| `hash` | `Hex` | Hash of the last transaction. |
| `hashes` | `readonly Hex[]` | Every submitted transaction, in order. |
| `id` | `string` | EIP-5792 bundle id when the calls were sent as one batch. |
| `plan` | `Plan` | The plan the write executed: its steps, in order, as they were submitted. |

## Wait for the receipt with `renounceGovernanceSync`

Renounces ownership of the HCA factory, freezing its implementation approvals (factory owner only). Resolves once the receipt is in.

Use when the next step depends on the change being on-chain.

`hcaAdmin.renounceGovernanceSync` takes the same options plus [`confirmations` and `timeout`](/docs/reference/sdk/client#sync-options).

Resolves to `Write.SyncResult`. Receipts plus the submitted hashes and plan.
