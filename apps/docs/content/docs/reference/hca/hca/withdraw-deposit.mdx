Withdraws ETH from the signer's HCA EntryPoint deposit. Resolves once the transaction is submitted.

## When to use

Use to recover a deposit the HCA no longer needs.

## Signature

```ts
function withdrawDeposit(
  client: Like,
  options: withdrawDeposit.Options & Write.Options,
): Promise<withdrawDeposit.ReturnType>
```

Call it as `ens.hca.withdrawDeposit(options)` on a client, or `Actions.hca.withdrawDeposit(client, options)`.

## Parameters

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `to` (required) | `string` |  | Recipient. |
| `amount` (required) | `bigint` |  | Wei to withdraw. |

Also takes the [write options](/docs/reference/sdk/client#write-options).

## Returns

Resolves to `Write.Result`. Submitted transaction hashes and the plan that produced them.

| Field | Type | Description |
| --- | --- | --- |
| `hash` | `Hex` | Hash of the last transaction. |
| `hashes` | `readonly Hex[]` | Every submitted transaction, in order. |
| `id` | `string` | EIP-5792 bundle id when the calls were sent as one batch. |
| `plan` | `Plan` | The plan the write executed: its steps, in order, as they were submitted. |

## Errors

| Error | Codes | When |

## Wait for the receipt with `withdrawDepositSync`

Withdraws ETH from the signer's HCA EntryPoint deposit. Resolves once the receipt is in.

Use when the next step depends on the change being on-chain.

`hca.withdrawDepositSync` takes the same options plus [`confirmations` and `timeout`](/docs/reference/sdk/client#sync-options).

Resolves to `Write.SyncResult`. Receipts plus the submitted hashes and plan.
