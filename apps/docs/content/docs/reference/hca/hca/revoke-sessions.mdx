Invalidates every session approval of the signer's HCA. Resolves once the transaction is submitted.

## When to use

Use when a session key may be lost or compromised, or to end all prompt-free access.

## Details

- Bumps the HCA's session nonce; must be the owner's own transaction (never routed through the
  HCA).

## Signature

```ts
function revokeSessions(
  client: Like,
  options: revokeSessions.Options & Write.Options,
): Promise<revokeSessions.ReturnType>
```

Call it as `ens.hca.revokeSessions(options)` on a client, or `Actions.hca.revokeSessions(client, options)`.

Also takes the [write options](/docs/reference/sdk/client#write-options).

## Returns

Resolves to `Write.Result`. Submitted transaction hashes and the plan that produced them.

| Field | Type | Description |
| --- | --- | --- |
| `hash` | `Hex` | Hash of the last transaction. |
| `hashes` | `readonly Hex[]` | Every submitted transaction, in order. |
| `id` | `string` | EIP-5792 bundle id when the calls were sent as one batch. |
| `plan` | `Plan` | The plan the write executed: its steps, in order, as they were submitted. |
