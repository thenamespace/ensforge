Asks the owner to approve a session key for their HCA, with one signature and no transaction.

## When to use

Use to enable prompt-free registration and record updates through Rhinestone (`hca(\{ session
\})`).

## Details

- The session may register names to the owner, deploy and edit `resolver` (one resolver per
  session), set the owner's primary name and approve registration payments.
- It stays valid until `validUntil` or until the owner calls `revokeSessions`. Store the
  returned session; it holds no secret.
- Refund ceilings default to the ENS app's: $20k per ETH, 500k gas of overhead, 100 USDC per
  intent.

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `sessionKey` (required) | `string` |  | Public address of the session key the app keeps. |
| `resolver` (required) | `string` |  | The one resolver the session may deploy and edit (an existing resolver, or a PermissionedResolver proxy the session deploys from the HCA at that address). |
| `validUntil` (required) | `number` |  | Unix seconds after which the session stops working. |
| `refund` | `{ readonly token?: Address \| undefined; readonly maxExchangeRate?: bigint \| undefined; readonly maxGasOverhead?: bigint \| undefined; readonly maxAmount?: bigint \| undefined; }` |  | Refund ceilings for Rhinestone executions, in the refund token's units. |
| `account` | `Address` |  | Signer (the HCA owner). @default the client's account |
