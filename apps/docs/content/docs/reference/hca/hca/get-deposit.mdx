Reads an HCA's ERC-4337 EntryPoint deposit, which pays for its UserOperations without a paymaster.

## When to use

Use with `bundler()` executions that the HCA pays for itself.

## Signature

```ts
function getDeposit(
  client: Like,
  options?: getDeposit.Options,
): Promise<getDeposit.ReturnType>
```

Call it as `ens.hca.getDeposit(options)` on a client, or `Actions.hca.getDeposit(client, options)`.

`hca.getDeposit.request(options)` builds a deferred read for `Actions.batch`. See [Look up many at once](/docs/sdk/look-up-many-at-once).

## Parameters

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `address` | `string` |  | The HCA's address. |
| `owner` | `string` | the client's account | Owner whose HCA to use. |

## Returns

Resolves to `bigint`. Deposit in wei.
