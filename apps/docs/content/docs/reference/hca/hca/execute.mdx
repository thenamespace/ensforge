Runs calls from the signer's HCA as one atomic execution. Resolves once the transaction is submitted.

## When to use

Use to batch arbitrary calls the HCA has authority for, or to recover funds the HCA holds.

## Details

- Runs through `via` (default `hca()`: the owner's wallet sends `executeByOwner`).
- Every call succeeds or the whole execution reverts.

## Signature

```ts
function execute(
  client: Like,
  options: execute.Options & Write.Options,
): Promise<execute.ReturnType>
```

Call it as `ens.hca.execute(options)` on a client, or `Actions.hca.execute(client, options)`.

## Parameters

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `calls` (required) | `readonly { readonly to: Address; readonly data?: Hex \| undefined; readonly value?: bigint \| undefined; }[]` |  | Calls to run, in order; `value` is paid from what the execution forwards. |

Also takes the [write options](/docs/reference/sdk/client#write-options).

## Returns

Resolves to `Write.Result`. Submitted transaction hashes and the plan that produced them.

| Field | Type | Description |
| --- | --- | --- |
| `hash` | `Hex` | Hash of the last transaction. |
| `hashes` | `readonly Hex[]` | Every submitted transaction, in order. |
| `id` | `string` | EIP-5792 bundle id when the calls were sent as one batch. |
| `plan` | `Plan` | The plan the write executed: its steps, in order, as they were submitted. |

## Errors

| Error | Codes | When |
| --- | --- | --- |
| [`HcaError`](/docs/reference/errors/hca-error) | [`HCA_NOT_VERIFIED`](/docs/reference/errors/HCA_NOT_VERIFIED), [`HCA_EXECUTOR_UNSUPPORTED`](/docs/reference/errors/HCA_EXECUTOR_UNSUPPORTED) | the HCA or executor cannot run them. |
| [`HcaError`](/docs/reference/errors/hca-error) | [`HCA_UNAVAILABLE`](/docs/reference/errors/HCA_UNAVAILABLE) | on chains without an HCA deployment. |

## Wait for the receipt with `executeSync`

Runs calls from the signer's HCA as one atomic execution. Resolves once the receipt is in.

Use when the next step depends on the change being on-chain.

`hca.executeSync` takes the same options plus [`confirmations` and `timeout`](/docs/reference/sdk/client#sync-options).

Resolves to `Write.SyncResult`. Receipts plus the submitted hashes and plan.
