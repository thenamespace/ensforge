Computes the address of an owner's ENS HCA, deployed or not.

## When to use

Use to show or fund an HCA before it exists; the address never changes, even after upgrades.

## Signature

```ts
function predictAddress(
  client: Like,
  options?: predictAddress.Options,
): Promise<predictAddress.ReturnType>
```

Call it as `ens.hca.predictAddress(options)` on a client, or `Actions.hca.predictAddress(client, options)`.

`hca.predictAddress.request(options)` builds a deferred read for `Actions.batch`. See [Look up many at once](/docs/sdk/look-up-many-at-once).

## Parameters

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `owner` | `string` | the client's account | The owner. |

## Returns

Resolves to `Address`. The HCA address.
