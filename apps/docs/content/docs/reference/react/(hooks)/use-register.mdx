Registers names: commit, wait the minimum age, then register, with every step in `steps`. Preset of `useWrite(Actions.registration.register)`.

It wraps [`registration.register`](/docs/reference/sdk/registration/register): the same options, result and errors.

## Signature

```ts
function useRegister(config?: Parameters<typeof useWrite>[1]): WriteResult< Parameters<typeof Actions.registration.register>[1], Actions.registration.register.ReturnType, Actions.registration.register.ErrorType >
```

## Examples

```tsx title="A button that sends it"
import { Duration } from "@ensforge/sdk"
import { useRegister } from "@ensforge/react"

function Send() {
  const { mutate, isPending } = useRegister()
  return <button disabled={isPending} onClick={() => mutate({ names: "alice.eth", duration: Duration.years(1) })}>Send</button>
}
```
