### `ReadConfig`

Settings of a read hook: its freshness, whether it runs, and an optional client.

```ts
type ReadConfig = Freshness & { /** * Run the read. Passing `undefined` options also disables it, e.g. until a name is typed. * * @default true */ readonly enabled?: boolean | undefined; /** Client to read with instead of the provider's. */ readonly client?: Ensforge.Client | undefined; };
```

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `staleTime` | `Duration.Input` |  | After this long, the next mount or window focus refetches in the background while the cached value is shown (stale-while-revalidate). `Duration.infinity` never does. Without it, a value hydrated from the server is stale after 30 seconds; a failed read is always stale, so a remount retries it. |
| `idleTTL` | `Duration.Input \| "forever"` | `"1 minute"` | How long an unused read stays cached; `"forever"` or `Duration.infinity` keeps it. With hooks of several settings, the longest applies. |
| `refetchInterval` | `Duration.Input` |  | Refetch on this interval while the read is in use, in the browser only. |
| `refreshOnWindowFocus` | `boolean` | `false` | Refetch when the window regains focus (respecting `staleTime` when set). |
| `enabled` | `boolean` | `true` | Run the read. Passing `undefined` options also disables it, e.g. until a name is typed. |
| `client` | `Ensforge.Client` |  | Client to read with instead of the provider's. |
