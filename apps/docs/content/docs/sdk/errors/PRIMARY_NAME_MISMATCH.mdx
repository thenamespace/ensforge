**Class** [`NotFoundError`](/docs/sdk/errors#notfounderror) · **Code** `PRIMARY_NAME_MISMATCH` · **Package** `@ensforge/sdk`

## What happened

The primary name does not resolve back to this address.

## What to show users

| Title | Message | Action |
| --- | --- | --- |
| Primary name not verified | The primary name of this address does not point back to it. |  |

## How to fix

Set the name's address record to this address, or set another primary name.

## Retry safety

Retrying the same call fails the same way until the cause is fixed (`retryable: false`).
