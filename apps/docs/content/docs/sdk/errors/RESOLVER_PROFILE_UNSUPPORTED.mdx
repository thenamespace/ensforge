**Class** [`UnsupportedError`](/docs/sdk/errors#unsupportederror) · **Code** `RESOLVER_PROFILE_UNSUPPORTED` · **Package** `@ensforge/sdk`

## What happened

The resolver does not support this record type.

## What to show users

| Title | Message | Action |
| --- | --- | --- |
| Not supported | This name's resolver does not support this record. | Switch to a resolver that supports it. |

## How to fix

Point the name at a resolver that supports it, e.g. the public resolver.

## Retry safety

Retrying the same call fails the same way until the cause is fixed (`retryable: false`).
