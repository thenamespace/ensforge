**Class** [`TransactionError`](/docs/sdk/errors#transactionerror) · **Code** `RECEIPT_TIMEOUT` · **Package** `@ensforge/sdk`

## What happened

Timed out waiting for the transaction receipt.

## What to show users

| Title | Message | Action |
| --- | --- | --- |
| Still pending | The transaction is taking longer than expected to confirm. | Check your wallet for its status before retrying. |

## How to fix

The transaction may still confirm; check it by hash before retrying.

## Retry safety

Retrying the same call fails the same way until the cause is fixed (`retryable: false`).
