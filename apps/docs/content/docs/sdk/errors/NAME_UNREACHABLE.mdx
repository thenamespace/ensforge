**Class** [`NameStateError`](/docs/sdk/errors#namestateerror) · **Code** `NAME_UNREACHABLE` · **Package** `@ensforge/sdk`

## What happened

ENSv2 resolution no longer reaches this ENSv1 name.

## What to show users

| Title | Message | Action |
| --- | --- | --- |
| Name unreachable | This name no longer resolves: ENSv2 resolution does not reach its ENSv1 records. |  |

## How to fix

ENSv2 resolves it elsewhere: an ancestor moved to ENSv2 without it, or ENSv2 holds no reservation for it. Ask the parent's owner to recreate it there.

## Retry safety

Retrying the same call fails the same way until the cause is fixed (`retryable: false`).
