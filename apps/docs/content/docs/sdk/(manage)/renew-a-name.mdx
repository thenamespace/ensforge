---
title: Renew a name
description: Quote and renew one or more .eth names for a chosen duration, including names that are already in their grace period after expiry.

---

You will extend the registration of one or more [`.eth` names](/docs/reference/glossary#eth-name). Anyone can renew any name: the signer pays, and the owner does not change. ensforge picks the right contract for each name, so [ENSv1](/docs/reference/glossary#ensv1) and [ENSv2](/docs/reference/glossary#ensv2) names renew in the same call.

## Prerequisites

- A wallet client that holds the payment token and gas. See [Create a client](/docs/sdk/create-a-client).
- Names that are registered or in their [grace period](/docs/reference/glossary#grace-period) (the time after [expiry](/docs/reference/glossary#expiry) when the name can still be renewed and nobody else can register it). Names past the grace period are registered again, not renewed. See [Register a name](/docs/sdk/register-a-name).

## 1. Quote the renewal

[`registration.getRenewalPrice`](/docs/reference/sdk/registration/get-renewal-price) quotes any number of names in one batched call.

**Example** (Quoting Two Names)

```ts title="renewal-price.ts"
import { sepolia } from "viem/chains";
import { Duration, Ensforge, ensActions } from "@ensforge/sdk";

const ens = Ensforge.create({
  chain: sepolia,
}).extend(ensActions());

const { total, token, items } = await ens.registration.getRenewalPrice({
  names: ["ensforge-docs-demo.eth", "ensforge-docs-demo-2.eth"],
  duration: Duration.years(1),
});
```

Each entry of `items` has the `name`, its `amount` and its `route`:

| `route`          | Contract                  | Names                                          |
| ---------------- | ------------------------- | ---------------------------------------------- |
| `"v2-registrar"` | The ENSv2 `ETHRegistrar`. | Names registered on ENSv2.                     |
| `"v1-renewer"`   | `ETHRenewerV1`.           | Names still on ENSv1, including wrapped names. |

## 2. Renew

[`registration.renew`](/docs/reference/sdk/registration/renew) sends one `renewBatch` call per route, with a token approval for each contract whose allowance is short. `registration.renewSync` also waits for the receipts.

**Example** (Renewing Two Names)

```ts title="renew.ts"
import { createWalletClient, http, type Hex } from "viem";
import { privateKeyToAccount } from "viem/accounts";
import { sepolia } from "viem/chains";
import { Duration, Ensforge, ensActions } from "@ensforge/sdk";

const account = privateKeyToAccount(process.env.PRIVATE_KEY as Hex);
const transport = http(process.env.SEPOLIA_RPC_URL);

const ens = Ensforge.create({
  chain: sepolia,
  transports: { [sepolia.id]: transport },
  wallet: createWalletClient({ account, chain: sepolia, transport }),
}).extend(ensActions());

const { hashes } = await ens.registration.renewSync({
  names: ["ensforge-docs-demo.eth", "ensforge-docs-demo-2.eth"],
  duration: Duration.years(1),
});
```

| Option         | Type                        | Default  | Description                                                     |
| -------------- | --------------------------- | -------- | --------------------------------------------------------------- |
| `names`        | `string \| string[]`        | required | `.eth` second-level names. A name listed twice is renewed once. |
| `duration`     | `bigint`                    | required | Renewal length in seconds.                                      |
| `paymentToken` | `"usdc" \| "dai" \| string` | `"usdc"` | Token to pay with.                                              |
| `referrer`     | `Hex`                       | none     | Referrer the registrar records.                                 |

`renew` returns `{ hash, hashes, id, plan }`. `renewSync` adds `receipt` and `receipts`, the renewed `names` with their new `expiry`, and `paid`, the amount charged in the token's smallest unit. All write options apply too. See [How writes work](/docs/sdk/writing-to-ens).

## Check the result

Read the name again to see its new `expiry`. See [Get a name's owner, expiry and status](/docs/sdk/get-name-details).

<Callout type="info" title="Delegating renewal">
  A `.eth` owner cannot grant the `renew` role to another account (`CANNOT_GRANT_ROLES`). It is not
  needed: anyone can renew through the registrar.
</Callout>

## Troubleshooting

### `NAME_NOT_RENEWABLE`

A name is neither registered nor in its grace period. Register it instead. See [`NAME_NOT_RENEWABLE`](/docs/reference/errors/NAME_NOT_RENEWABLE).

### `INSUFFICIENT_TOKEN_BALANCE`

The signer cannot pay the quote. See [`INSUFFICIENT_TOKEN_BALANCE`](/docs/reference/errors/INSUFFICIENT_TOKEN_BALANCE).

### `DURATION_TOO_SHORT`

`duration` is shorter than the registrar's minimum. See [`DURATION_TOO_SHORT`](/docs/reference/errors/DURATION_TOO_SHORT).

### `PAYMENT_TOKEN_UNSUPPORTED`

The registrar does not accept `paymentToken`. See [`PAYMENT_TOKEN_UNSUPPORTED`](/docs/reference/errors/PAYMENT_TOKEN_UNSUPPORTED).

### `UNSUPPORTED_ON_DEPLOYMENT`

The chain has no ENSv2 deployment. See [`UNSUPPORTED_ON_DEPLOYMENT`](/docs/reference/errors/UNSUPPORTED_ON_DEPLOYMENT).
