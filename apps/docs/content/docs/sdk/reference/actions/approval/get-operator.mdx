**Read** · Batchable · Stable · Since 1.0.0

Checks whether an operator may manage everything an owner holds on an ENS contract
(`isApprovedForAll`).

## When to use

Use to see whether a marketplace, manager or contract wallet is already approved.

## Parameters

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `owner` (required) | `string` |  | Account that granted the approval. |
| `operator` (required) | `string` |  | Account that may be approved. |
| `contract` (required) | `ApprovalContract` |  | `"registry"`, `"registrar"`, `"wrapper"`, or a registry or resolver address. |

Also takes the [read options](/docs/sdk/reference/client#read-options).

## Returns

Resolves to `boolean`. Whether `operator` is approved for all of `owner`'s names on the contract.
