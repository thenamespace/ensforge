**Write** · Stable · Since 1.0.0

Approves or revokes an operator for everything the signer holds on an ENS contract (`setApprovalForAll`). Resolves once the transaction is submitted.

## When to use

Use to let a marketplace or manager act on all your names in one contract. Use [`setOperatorSync`](/docs/sdk/reference/actions/approval/set-operator#wait-for-the-receipt-with-setoperatorsync) to wait for the receipt.

## Parameters

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `operator` (required) | `string` |  | Account to approve or revoke. |
| `approved` (required) | `boolean` |  | `true` to approve the operator, `false` to revoke it. |
| `contract` (required) | `ApprovalContract` |  | `"registry"`, `"registrar"`, `"wrapper"`, or a registry or resolver address. |

Also takes the [write options](/docs/sdk/reference/client#write-options).

## Returns

Resolves to `Write.Result`. Submitted transaction hashes and the plan that produced them.

| Field | Type | Description |
| --- | --- | --- |
| `hash` | `Hex` | Hash of the last transaction. |
| `hashes` | `readonly Hex[]` | Every submitted transaction, in order. |
| `id` | `string` | EIP-5792 bundle id when the calls were sent as one batch. |
| `plan` | `Plan` | The plan the write executed: its steps, in order, as they were submitted. |

## Wait for the receipt with `setOperatorSync`

Approves or revokes an operator for everything the signer holds on an ENS contract (`setApprovalForAll`). Resolves once the receipt is in.

Use when the next step depends on the change being on-chain.

`approval.setOperatorSync` takes the same options plus [`confirmations` and `timeout`](/docs/sdk/reference/client#sync-options).

Resolves to `Write.SyncResult`. Receipts plus the submitted hashes and plan.

## Details

- `contract`: the ENSv1 `"registry"`, `"registrar"` or `"wrapper"`, or any ENSv2 registry
  or resolver by address.
- On ENSv2 registries an operator can transfer names; other changes need roles.
