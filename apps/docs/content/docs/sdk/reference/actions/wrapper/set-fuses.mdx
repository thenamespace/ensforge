**Write** · Stable · Since 1.0.0

Burns owner-controlled fuses on a wrapped ENSv1 name. Resolves once the transaction is submitted.

## When to use

Use to give up powers over a name for good, such as unwrapping or changing its resolver. Use [`setFusesSync`](/docs/sdk/reference/actions/wrapper/set-fuses#wait-for-the-receipt-with-setfusessync) to wait for the receipt.

## Wait for the receipt with `setFusesSync`

Burns owner-controlled fuses on a wrapped ENSv1 name. Resolves once the receipt is in.

Use when the next step depends on the change being on-chain.

`wrapper.setFusesSync` takes the same options plus [`confirmations` and `timeout`](/docs/sdk/reference/client#sync-options).

Resolves to `Write.SyncResult`. Receipts plus the submitted hashes and plan.

## Details

- Fuses cannot be unburned before the name expires.
- Needs `parentCannotControl`, burned by the parent or set on every wrapped `.eth` name;
  every fuse besides `cannotUnwrap` needs `cannotUnwrap`.

<Callout type="warn" title="Gotchas">

- Burning `cannotUnwrap` keeps the name in the NameWrapper until it expires.

</Callout>
