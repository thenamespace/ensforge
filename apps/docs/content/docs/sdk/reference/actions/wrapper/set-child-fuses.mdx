**Write** · Stable · Since 1.0.0

Burns fuses on, or extends, a wrapped ENSv1 subname as its parent's owner. Resolves once the transaction is submitted.

## When to use

Use to emancipate a subname (`parentCannotControl`), let it renew itself (`canExtendExpiry`), or extend it. Use [`setChildFusesSync`](/docs/sdk/reference/actions/wrapper/set-child-fuses#wait-for-the-receipt-with-setchildfusessync) to wait for the receipt.

## Details

- Sent by the owner of the wrapped parent.
- `expiry` only grows, and is capped at the parent's expiry. Burning `parentCannotControl`
  without `expiry` uses the parent's expiry, so the emancipated name does not expire at once.

<Callout type="warn" title="Gotchas">

- Burning `parentCannotControl` or `canExtendExpiry` needs `cannotUnwrap` on the parent
  ([`INVALID_RECORD_VALUE`](/docs/sdk/errors/INVALID_RECORD_VALUE)). `parentCannotControl` gives up the parent's control of the
  subname until it expires: the parent can then only extend it ([`FUSE_BURNED`](/docs/sdk/errors/FUSE_BURNED) for new fuses).

</Callout>
