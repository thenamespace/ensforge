**Read** · Stable · Since 1.0.0

Watches one name's ENS events as new blocks arrive. Resolves to a function that stops watching.

## When to use

Use to update a name's page live, or to react when another account changes the name.

## Usage

```ts title="Watching a name"
const unwatch = await ens.event.watch({ name: "nick.eth", onEvents: (events) => console.log(events) })
```

## Parameters

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `name` (required) | `string` |  | ENS name. Normalized automatically. |
| `types` | `readonly EventType[]` |  | Only these event types. |
| `pollingInterval` | `number` |  | Milliseconds between polls. |
| `onEvents` (required) | `(events: readonly Event[]) => void` |  | Called with each new batch of events. |
| `onError` | `((error: AnyError) => void)` |  | Called when a poll fails; watching continues. |

## Returns

Resolves to `() => void`. Stops watching.

## Details

- Every new block range is read like [`event.get`](/docs/sdk/reference/actions/event/get), so resolver and registry
  changes during the watch are followed.
- Polls at the public client's `pollingInterval` unless `pollingInterval` is given.
