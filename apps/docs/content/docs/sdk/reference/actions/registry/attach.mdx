**Write** · Stable · Since 1.0.0

Sets or removes the subregistry of an ENSv2 name. Resolves once the transaction is submitted.

## When to use

Use to move a name's children to another registry, or to detach them. Use [`attachSync`](/docs/sdk/reference/actions/registry/attach#wait-for-the-receipt-with-attachsync) to wait for the receipt.

## Parameters

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `name` (required) | `string` |  | ENSv2 name. Normalized automatically. |
| `registry` (required) | `string \| null` |  | Registry to attach, or `null` to detach. |
| `setParent` | `boolean` | `true` | Also call `setParent` on the registry. |

Also takes the [write options](/docs/sdk/reference/client#write-options).

## Returns

Resolves to `Write.Result`. Submitted transaction hashes and the plan that produced them.

| Field | Type | Description |
| --- | --- | --- |
| `hash` | `Hex` | Hash of the last transaction. |
| `hashes` | `readonly Hex[]` | Every submitted transaction, in order. |
| `id` | `string` | EIP-5792 bundle id when the calls were sent as one batch. |
| `plan` | `Plan` | The plan the write executed: its steps, in order, as they were submitted. |

## Wait for the receipt with `attachSync`

Sets or removes the subregistry of an ENSv2 name. Resolves once the receipt is in.

Use when the next step depends on the change being on-chain.

`registry.attachSync` takes the same options plus [`confirmations` and `timeout`](/docs/sdk/reference/client#sync-options).

Resolves to `Write.SyncResult`. Receipts plus the submitted hashes and plan.

## Details

- `setSubregistry` on the registry holding the name, then `setParent` on the new registry so
  its canonical name points back to the name (skip with `setParent: false`).
- `registry: null` detaches the current subregistry.
