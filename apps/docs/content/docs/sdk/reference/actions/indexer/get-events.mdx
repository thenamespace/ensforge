**Read** · Batchable · Stable · Since 1.0.0

Searches indexed ENS events by name, address, resolver, contract or block range.

## When to use

Use to audit events across names, e.g. every event a resolver emitted or a block range.

## Usage

<Tabs groupId="api" items={["Client","Standalone","Effect"]} persist>

<Tab>

```ts title="Reading a resolver's events"
const page = await ens.indexer.getEvents({ resolver: { address: "0x231b…" } })
```

</Tab>

<Tab>

```ts title="Reading a block range with a standalone call"
import { Actions } from "@ensforge/sdk"

const page = await Actions.indexer.getEvents(ens, { fromBlock: 26_000_000n, toBlock: 26_000_100n })
```

</Tab>

<Tab>

```ts title="Reading registrations in an Effect program"
import { Actions } from "@ensforge/sdk/effect"

const page = yield* Actions.indexer.getEvents(ens, { types: ["registration"], order: "desc" })
```

</Tab>

`indexer.getEvents.request(options)` builds a deferred read for `Actions.batch`. See [Look up many at once](/docs/sdk/look-up-many-at-once).
