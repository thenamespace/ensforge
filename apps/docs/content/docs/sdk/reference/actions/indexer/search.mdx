**Read** · Batchable · Stable · Since 1.0.0

Searches names by text.

## When to use

Use to back a name search box or autocomplete.

| `limit` | `number` |  | Rows per page, 1–200. @default 50 |

| `includeTotal` | `boolean` |  | Count every row (`totalCount`); slower. |
| `query` (required) | `string` |  |  |

Also takes the [read options](/docs/sdk/reference/client#read-options).

## Returns

Resolves to `Page<IndexedName>`. One page of matching names.

## Details

- Matches from the start of a label by default; `match: "contains"` matches anywhere.
- Searches every namespace the indexer serves unless `namespace` is set.
