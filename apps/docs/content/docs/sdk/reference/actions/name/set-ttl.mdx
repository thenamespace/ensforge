**Write** · Stable · Since 1.0.0

Sets the ENSv1 registry TTL of a name. Resolves once the transaction is submitted.

## When to use

Use to change how long resolvers may cache the name's records. Use [`setTtlSync`](/docs/sdk/reference/actions/name/set-ttl#wait-for-the-receipt-with-setttlsync) to wait for the receipt.

## Wait for the receipt with `setTtlSync`

Sets the ENSv1 registry TTL of a name. Resolves once the receipt is in.

Use when the next step depends on the change being on-chain.

`name.setTtlSync` takes the same options plus [`confirmations` and `timeout`](/docs/sdk/reference/client#sync-options).

Resolves to `Write.SyncResult`. Receipts plus the submitted hashes and plan.

## Details

- ENSv2 has no registry TTL.
