| Action | Kind | Description |
| --- | --- | --- |
| [`permission.check`](/docs/sdk/reference/actions/permission/check) | Read, batchable | Checks whether an account may perform one operation on an ENS name, and lists exactly what it lacks when it may not. |
| [`permission.get`](/docs/sdk/reference/actions/permission/get) | Read, batchable | Reads what an account may do with an ENS name: transfer it, change its resolver, edit records, create subnames and more, across ENSv1 ownership and ENSv2 roles. |
| [`permission.setRecordAccess`](/docs/sdk/reference/actions/permission/set-record-access) | Write | Lets another account edit a name's records, or takes that access back. |
