Call them as `ens.record.<action>(options)` on a client, or `Actions.record.<action>(client, options)`.

| Action | Kind | Description |
| --- | --- | --- |
| [`record.get`](/docs/sdk/reference/actions/record/get) | Read, batchable | Reads any mix of a name's records in one request: texts, addresses, content hash, ABI, public key, name record, interface implementers and data records. |
| [`record.getAddress`](/docs/sdk/reference/actions/record/get-address) | Read, batchable | Reads one address record of an ENS name, for Ethereum by default or any coin (ENSIP-9, ENSIP-11). |
| [`record.getAvatar`](/docs/sdk/reference/actions/record/get-avatar) | Read, batchable | Reads the avatar of an ENS name and resolves it to a URL a browser can load (ENSIP-12). |
| [`record.getContentHash`](/docs/sdk/reference/actions/record/get-content-hash) | Read, batchable | Reads the content hash of an ENS name (ENSIP-7), decoded into its protocol, value and URI. |
| [`record.getText`](/docs/sdk/reference/actions/record/get-text) | Read, batchable | Reads one text record of an ENS name, such as `url`, `avatar` or `com.twitter`. |
| [`record.set`](/docs/sdk/reference/actions/record/set) | Write | Writes records of an ENS name and resolves once the transaction is submitted. |
