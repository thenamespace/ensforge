**Read** · Batchable · Stable · Since 1.0.0

Reads any mix of a name's records in one request: texts, addresses, content hash, ABI, public
key, name record, interface implementers and data records.

## When to use

Use to load a profile or several records at once. Use `record.getText` or
`record.getAddress` for a single value.

## Parameters

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `texts` | `readonly string[]` |  | Text record keys, e.g. `["url", "avatar", "com.twitter"]`. |
| `addresses` | `readonly (string \| bigint)[]` |  | Coins by symbol (`"eth"`, `"btc"`, `"base"`) or coin type (`2147492101n`). EVM chains fall back to the default EVM address (ENSIP-19). |
| `contentHash` | `true` |  | Read the content hash (ENSIP-7). |
| `abi` | `true \| { readonly contentTypes: bigint }` |  | Read the ABI record (ENSIP-4); `contentTypes` is a bitmask of acceptable types. |
| `pubkey` | `true` |  | Read the SECP256k1 public key. |
| `nameRecord` | `true` |  | Read the `name` record (ENSIP-3), used for reverse resolution. |
| `interfaces` | `readonly Hex[]` |  | ERC-165 interface IDs to read implementers for. |
| `data` | `readonly string[]` |  | Data record keys (ENSIP-24). |
| `name` (required) | `string` |  | ENS name to read. Normalized automatically. |

Also takes the [read options](/docs/sdk/reference/client#read-options).

## Returns

Resolves to `Records<selection>`. The selected records.

## Details

- One Universal Resolver call, whatever the selection (ENSv1, ENSv2, wildcard and off-chain
  names). ENSv1 names answered through the ENSv1 bridge cost one more batched call, to report
  the ENSv1 resolver behind it in `resolver`.
- The result has exactly the selected fields: `texts.url` exists only when `"url"` was
  requested.
- Missing records are `null`. A missing resolver gives `resolver: null` and every record `null`,
  unless `strict` is set.
- EVM chain addresses fall back to the default EVM address (ENSIP-19).
