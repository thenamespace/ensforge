**Read** · Batchable · Stable · Since 1.0.0

Fetches the DNSSEC proof of a DNS name's `_ens` TXT record.

## When to use

Use to fetch a proof once and pass it to [`dns.claim`](/docs/sdk/reference/actions/dns/claim), or to inspect it.

## Parameters

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `name` (required) | `string` |  | DNS name. Normalized automatically. |
| `gatewayUrls` | `readonly string[]` |  | DNSSEC gateways to use instead of the deployment's. |

Also takes the [read options](/docs/sdk/reference/client#read-options).

## Returns

Resolves to `Proof`. Signed RRSets, the record's TXT strings and its signature times.

| Field | Type | Description |
| --- | --- | --- |
| `name` | `string` | DNS name the proof is for, e.g. `_ens.example.com`. |
| `rrsets` | `readonly SignedRRSet[]` | Signed RRSets, root first. |
| `inception` | `number` | Signature inception of the proven record set, as a Unix timestamp; `0` when it does not exist. |
| `expiration` | `number` | Signature expiration of the proven record set, as a Unix timestamp; `0` when it does not exist. |
| `txt` | `readonly string[]` | TXT strings of the proven record set; empty when the record does not exist. |

## Details

- Fetched from the deployment's DNSSEC gateway (ENSIP-17) unless `gatewayUrls` is given.
- Not verified; [`dns.getStatus`](/docs/sdk/reference/actions/dns/get-status) verifies it on-chain.
