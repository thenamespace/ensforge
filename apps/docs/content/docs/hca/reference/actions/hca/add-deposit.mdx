Adds ETH to an HCA's ERC-4337 EntryPoint deposit. Resolves once the transaction is submitted.

## When to use

Use when `bundler()` executions are paid by the HCA itself rather than a paymaster.

## Parameters

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `amount` (required) | `bigint` |  | Wei to deposit. |
| `address` | `string` |  | The HCA's address. @default the signer's HCA |

Also takes the [write options](/docs/sdk/reference/client#write-options).

## Returns

Resolves to `Write.Result`. Submitted transaction hashes and the plan that produced them.

| Field | Type | Description |
| --- | --- | --- |
| `hash` | `Hex` | Hash of the last transaction. |
| `hashes` | `readonly Hex[]` | Every submitted transaction, in order. |
| `id` | `string` | EIP-5792 bundle id when the calls were sent as one batch. |
| `plan` | `Plan` | The plan the write executed: its steps, in order, as they were submitted. |

## Errors

| Error | Codes | When |
| --- | --- | --- |
| [`InvalidInputError`](/docs/sdk/errors#invalidinputerror) | [`INVALID_ADDRESS`](/docs/sdk/errors/INVALID_ADDRESS) | an invalid address. |
| [`HcaError`](/docs/sdk/errors#hcaerror) | [`HCA_UNAVAILABLE`](/docs/sdk/errors/HCA_UNAVAILABLE) | on chains without an HCA deployment. |

It can also fail with the errors every write can (`Errors.WriteError`: the common errors plus `InsufficientFundsError`, `TransactionError`, `UnsupportedError`, `UserRejectedError`, `WalletError`).

See [How errors work](/docs/sdk/errors-explained).

## Plan methods

Each method takes the same options as `hca.addDeposit` and sends nothing. See [Preview before sending](/docs/sdk/preview-before-sending).

| Method | Description |
| --- | --- |
| `hca.addDeposit.prepare(options)` | Builds the plan without sending anything. |
| `hca.addDeposit.simulate(options)` | Simulates the plan with `eth_call`, reporting each step. |
| `hca.addDeposit.estimateGas(options)` | Estimates the gas and ETH the plan needs. |

## Wait for the receipt with `addDepositSync`

Adds ETH to an HCA's ERC-4337 EntryPoint deposit. Resolves once the receipt is in.

Use when the next step depends on the change being on-chain.

`hca.addDepositSync` takes the same options plus [`confirmations` and `timeout`](/docs/sdk/reference/client#sync-options).

Resolves to `Write.SyncResult`. Receipts plus the submitted hashes and plan.
