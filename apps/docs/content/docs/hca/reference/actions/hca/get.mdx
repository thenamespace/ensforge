Reads an ENS HCA (Hosted Contract Account): its address, owner, implementation, session nonce and verification problems.

## When to use

Use to show a user's HCA, or to check it before routing writes through it; works before
deployment (predicted address).

## Usage

## Parameters

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `address` | `string` |  | The HCA's address. |
| `owner` | `string` | the client's account | Owner whose HCA to use. |

## Returns

Resolves to `HcaAccount`. The account, deployed or predicted.

| Field | Type | Description |
| --- | --- | --- |
| `address` | `Address` |  |
| `owner` | `Address \| null` | The immutable owner (the wallet); `null` when it cannot be read. |
| `deployed` | `boolean` |  |
| `authorizedOwner` | `Address \| null` | Owner the factory certified for this account. |
| `accountId` | `string \| null` | `accountId()`, e.g. `ens-standalone-hca.1.1.0`. |
| `implementation` | `Address \| null` | Current implementation; `null` before deployment. |
| `initialImplementation` | `Address` | Implementation the address derives from; it never changes. |
| `sessionNonce` | `bigint` | Increments with `revokeSessions`, invalidating every session approval. |
| `upgradeSet` | `Address` | DAO set of implementations this account may upgrade to. |
| `problems` | `readonly HcaProblem[]` | Failed checks; empty for a usable (or not yet deployed) HCA. |

It can also fail with the errors every read can (`Errors.CommonError`: `ConfigError`, `ContractRevertError`, `InternalError`, `NetworkError`).

See [How errors work](/docs/sdk/errors-explained).

## Details

- Without `address`, reads the HCA of `owner` (default: the client's account).
- `problems` lists failed checks (HCA.md): an empty list means the account is safe to use.
