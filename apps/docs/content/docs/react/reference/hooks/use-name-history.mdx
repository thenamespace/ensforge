Lists a name's events (registrations, transfers, record changes), page by page, from the indexer. Preset of `useInfiniteRead(Actions.indexer.getHistory, …)`.

It wraps [`indexer.getHistory`](/docs/sdk/reference/actions/indexer/get-history): the same options, result and errors.

## Usage

```tsx title="A list with \"Load more\""
import { useNameHistory } from "@ensforge/react"

function List() {
  const { items, hasMore, loadMore } = useNameHistory({ name: "nick.eth" })
  return <button disabled={!hasMore} onClick={loadMore}>{items.length}</button>
}
```
