Stable · Since 1.0.0

Reads any mix of a name's records in one request; the result has exactly the requested fields.
Preset of `useRead(Actions.record.get, …)`.

It wraps [`record.get`](/docs/sdk/reference/actions/record/get): the same options, result and errors.

## Usage

```tsx title="A profile card"
import { useRecords } from "@ensforge/react"

function Profile() {
  const { data } = useRecords({ name: "nick.eth", texts: ["url", "avatar"], addresses: ["eth"] })
  return <span>{data?.texts.url}</span>
}
```
