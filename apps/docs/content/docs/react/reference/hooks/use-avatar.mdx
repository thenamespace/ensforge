Reads a name's avatar as an image URL, with NFT avatars resolved. Preset of `useRead(Actions.record.getAvatar, …)`.

It wraps [`record.getAvatar`](/docs/sdk/reference/actions/record/get-avatar): the same options, result and errors.

## Usage

```tsx title="Reading in a component"
import { useAvatar } from "@ensforge/react"

function View() {
  const { data: avatar } = useAvatar({ name: "nick.eth" })
  return <img src={avatar ?? undefined} />
}
```
